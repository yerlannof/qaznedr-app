# D2 «Сланец / сера»: сценарий прокрутки для блока «Экспертиза»

**Статус.** Владелец выбрал направление D2 и поддержал идею раскрывать геологическую экспертизу при прокрутке. Описанный ниже конкретный сценарий — предложение на рассмотрении, а не утверждённая анимация или задание на реализацию.

## Место в странице

Сначала — компактный первый экран: кто мы, масштаб геологической базы и прямые действия **WeChat** (главное для китайской версии) и **WhatsApp**. Секция «Экспертиза» следует после него. Пользователь может связаться сразу, не проходя сцену. Контакт остаётся доступен во время просмотра и после него.

## Смысл сцены

Схематический керн служит опорой для объяснения работы геологов. Анимация показывает, как специалист выделяет интервал для изучения, сопоставляет архивные данные с полевыми наблюдениями и формулирует следующий вопрос. Она не изображает открытие запасов, содержание металла или право компании на участок. Серно-жёлтый означает **фокус анализа**, а не «найденную руду».

## Три состояния при обычной прокрутке

Проценты ниже — начальный ориентир для просмотра, не утверждённый тайминг.

| Ход секции | Изображение                                                                                                                        | Сопроводительный смысл                                          |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 0–30%      | Цельный схематический керн, читаемые границы слоёв.                                                                                | «Изучаем фондовые материалы и задаём вопросы к геологии».       |
| 30–65%     | Интервалы немного расходятся вдоль общей оси; центральный интервал выделяется серно-жёлтым. Исходная связь слоёв остаётся видимой. | «Выбираем фрагмент для проверки и сопоставления с источниками». |
| 65–100%    | Выбранный интервал слегка увеличивается. Рядом: **«Сопоставляем архивные данные и полевые наблюдения»**.                           | Появляется следующий шаг: **«Обсудить проект»**.                |

Экспертизу подтверждает не эффект движения сам по себе, а конкретная связка «наблюдение → вопрос геолога → источник → проверка». В окончательных текстах можно назвать тип источника и полевого наблюдения, только если компания подтвердит их. Рисунок и подписи схематические; перед публикацией их сверяет геолог.

## Характер движения

- Движение подчинено прокрутке, без автоматического цикла, постоянного вращения, вспышек, свечения и резкого появления.
- Глубина параллакса около **12–24 px на десктопе**, разлёт интервалов около **24–48 px** — стартовые ориентиры для проверки читаемости, не финальные значения.
- Ось и порядок интервалов сохраняются: зритель узнаёт тот же керн во всех состояниях. Выделение не скрывает соседние слои.
- На десктопе допустим ограниченный sticky-участок порядка **1,5–2 высот экрана**. Вход и выход естественные; колесо и жесты не перехватываются, прокрутка страницы не блокируется.
- Цвета D2: сланец `#253740`, мел `#E9ECE6`, сера `#DDE55E`. Жёлтый акцент — на тёмной поверхности; на светлой нужен тёмный текст. Без градиентов.

## Мобильная версия и доступность

На ширине 375 px, включая встроенный браузер WeChat, вместо длительного закрепления — последовательные короткие иллюстрированные блоки с теми же тремя смысловыми состояниями. Обязательной 3D-сцены нет. Кнопки связи остаются видимыми и удобными для нажатия.

При reduced motion, экономии ресурсов или отсутствии JavaScript показывается статичная содержательная версия: цельный керн, выбранный интервал, объяснение работы геолога и CTA. Все сведения доступны без анимации. Первый экран не ждёт загрузки тяжёлого ассета.

## Материалы и следующий шаг

Для будущей реализации подготовить раздельно экспортируемые элементы: цельный керн, отдельные срезы, слой выделения и подписи. Технологию и реализацию выбирает Claude Code **после утверждения** сценария. Соседний `d2-scroll-storyboard.png` — визуальный ориентир другого агента, а не геологическая документация.
