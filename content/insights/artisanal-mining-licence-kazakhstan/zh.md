个体小规模采矿，是针对砂矿和技术成因矿床中贵金属、宝石开采的单独制度。哈萨克斯坦公民可以取得此类许可证。首先核查区域和拟采用的作业方式：在地图上找到黄金，不等于取得开采权。

本文依据截至2026年9月29日核查的规定编写，仅供一般参考；具体矿区的限制须另行核查。

## 此类许可证适合您吗？

根据《底土与底土利用法典》（以下简称《底土法》）第263条，一人只能持有一张个体小规模采矿许可证。其权利不得转让给他人，也不得设定负担。因此，“购买现有采矿许可证”的提议须格外谨慎：通常不能出售此项权利。

许可证适用于法定范围内的手工作业或小功率设备作业，不能替代工业开采许可证。外国投资者需考虑其他法律制度；参见[外国投资者指南](/zh/insights/foreign-investor-subsoil-rights-kazakhstan)。

许可证有效期三年；满足第268条条件时可延长一次，延长期三年。区块面积为500平方米至5公顷（第269条）。

## 第一步：核查区域

各州地方执行机关在完成必要协调后划定个体小规模采矿区域。不能从地质图上任意选一个地点就开工。

向州政府及EPN核查最新信息：

- 该区域是否已划定用于个体小规模采矿；
- 他人是否已取得该区域的同类许可证；
- 是否存在区域性禁令；
- 土地及底土权利属于谁，是否需要其同意；
- 边界和面积是否符合此制度。

例如，第264条排除若干保护区、居民点及其周边1000米区域。这并非全部禁令。在私人土地、其他使用人的土地或他人的底土区块上作业，须考虑法律要求的同意。

地质图有助于理解地质情况。作业权和区域法律状态须根据其他信息核查。参见[如何选择地质图](/zh/insights/geological-map-kazakhstan)。

## 第二步：确定作业方式

事先列出设备并描述作业类型和方法。使用机械时需要个体小规模采矿计划；开展此类作业须取得该计划的国家环境审查正面结论（第273条）。

第270条的主要限制：

| 核查事项           | 限制                        |
| ------------------ | --------------------------- |
| 钻探及土方工程深度 | 从区块地表最低点起不超过3米 |
| 货车               | 一辆，载重量不超过10吨      |
| 挖掘机和／或推土机 | 铲斗容积合计不超过0.5立方米 |
| 该条所列机械       | 须为底土利用人所有          |
| 砂金               | 每日历年不超过50公斤        |
| 试剂与爆炸物       | 禁止使用                    |
| 土壤与采出的岩土   | 不得运出区块                |

还禁止建造永久性建筑物。在水体及水资源基金用地上，只能手工作业（第271条）。第273条关于环境筛查的规定，并不构成在那里使用挖掘机的一般许可。

先核查允许采用的技术，再选择设备。一般情况下可以租用机械，不代表在具体许可证下可以使用租来的机械。

## 第三步：准备申请和文件

现行第339号规则规定通过底土利用统一平台（EPN）提交申请。服务由州地方执行机关提供。

需准备：

- 载明区域、坐标和面积的申请书；
- 由代理人申请时，证明其权限的文件；
- 机械及设备清单、计划作业说明；
- 权利人的必要同意；
- 如在许可证第一年计划使用机械，提交个体小规模采矿计划。

规则附件3明确电子文件格式，以及通过EPN签署同意文件；部分信息从国家系统获取。同时，《底土法》第265条第4至5款要求随附副本经公证，以及申请和文件以哈萨克语、俄语编写。电子格式本身不取消这些要求。提交前，请向服务提供机关确认您的文件包如何在EPN中满足要求。

官方入口为[EPN政府服务](https://minerals.e-qazyna.kz/ru/minerals/gosuslugi)。选择个体小规模采矿许可证服务，并查看当前服务页面。

## 第四步：等待决定并满足开工条件

规则规定政府服务办理期限为七个工作日。重叠区域的申请按顺序审查；较早的申请可能影响您的程序及时间。因此，七天不代表任何情况下都能取得区块。

政府服务免费，但仍可能产生其他费用。《底土法》规定签约奖金、作业后果消除保证和土地复垦义务。每公顷保证金额由州执行机关确定；须核查具体区块及年度的最终金额。

开工前须满足适用要求，包括提供后果消除保证。保存许可证、计划、审查结论及履行条件的证明。此后须报告开采情况；通常应于1月30日前提交上一年度的年报（第272条）。

## 2026年有什么变化？

2026年3月17日第103号令更新了程序：通过EPN提交并登记申请，在个人账户显示状态，并以电子方式办理规定的同意。程序变化没有取消《底土法》对采矿活动的限制。

官方法令页面记载的发布日期为2026年3月19日。法令在首次正式公布之日起满60个日历日后生效；按该日期计算为2026年5月19日。本文在核查日采用更新后的第339号规则。

## 常见问题

**可以购买其他采矿人的许可证吗？** 不可以。个体小规模采矿许可证下的权利禁止转让。其他许可证另有规定；参见[底土利用权转让指南](/zh/insights/subsoil-rights-transfer-permission-kazakhstan)。

**有黄金的地方都能开采吗？** 不能。须核查区域制度和限制，并取得具体区块的权利。

**提交申请后可立即订购挖掘机吗？** 先等待决定，再核查允许的机械、所有权、计划、环境审查和其他开工条件。

**地图能说明矿区潜力吗？** 地图只是资料之一。应考虑比例尺、日期、标注对象类型及数据局限。地图本身不能证明储量或开采权。
