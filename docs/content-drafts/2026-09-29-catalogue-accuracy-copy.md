# Точечные правки обещаний о витрине — пакет владельцу, 29.09.2026

**Статус: предложения, не публикация.** На 29.09.2026 публичный API участков вернул `total: 0` (см. [технический аудит](../visibility/2026-09-29-seo-technical-audit.md)); это текущий снимок, не утверждение, что витрина останется пустой. Ниже только точные русские фрагменты четырёх опубликованных гайдов, RU description каталога и английские фрагменты `llms.txt`. Утверждение публичного текста — решение Ерлана. После него нужно синхронно подготовить KZ/EN/ZH аналоги гайдов и description, проверить смысл переводов и обновить код; этот файл не меняет ни один опубликованный текст.

Главная редакционная формула: **услуга подбора, анализа и проверки доступна для обсуждения; карточки показываются на странице участков, только когда утверждены и опубликованы; статус конкретного участка устанавливается отдельно на дату проверки**. Она не обещает текущий список или готовую карту. Для нулевой выдачи на самой странице каталога нужен отдельный видимый текст: «Сейчас опубликованных карточек нет. Опишите регион, металл и задачу — обсудим подбор и проверку материалов». Этот текст должен появляться только при нуле и исчезать при публикации карточек.

`content/insights/reserve-classification-gkz-kazrc-jorc-gbt17766/ru.md`, раздел «Как QAZNEDR HOLDING указывает стандарт в тизерах» и последняя фраза раздела «Чем поможет».

**Сейчас:** «На сайте и в карточках на [витрине участков](/ru/leads) мы пишем:

Ни один объект на витрине пока не оценён по KAZRC или JORC. Среднее содержание подписываем отдельно от ураганных и шлиховых проб. Участки на витрине свободны по нашей проверке на дату, указанную в карточке; холдингу они не принадлежат, право недропользования выдаёт государство. Название, координаты и материалы показываем на встрече после подписания NDA.»

**Предлагается заменить раздел целиком:**

«## Как читать оценки в карточке участка

Если карточка участка опубликована на [витрине](/ru/leads), сначала найдите стандарт и дату оценки. Категории ГКЗ СССР (A, B, C1, C2), историческая оценка и отчёт по KAZRC/JORC не взаимозаменяемы. P1–P3 обозначают прогнозные ресурсы, а не запасы. Среднее содержание нужно отличать от максимальной отдельной пробы и шлиховой пробы; без исходных материалов и метода расчёта числа нельзя сравнивать напрямую.

Карточка может содержать только часть сведений. Наличие геологических данных не подтверждает, что участок доступен для лицензирования: статус и ограничения проверяют отдельно на дату решения. Публикация карточки сама по себе не означает принадлежность участка холдингу. Точные координаты и дополнительные материалы раскрываем после встречи и подписания NDA.»

**Сейчас, финальная фраза:** «Участки — на [витрине](/ru/leads), вопросы — через [контакты](/ru/contact).»

**Предлагается:** «Опубликованные карточки, если они есть, — на [странице участков](/ru/leads); вопросы по исходным данным — через [контакты](/ru/contact).»
