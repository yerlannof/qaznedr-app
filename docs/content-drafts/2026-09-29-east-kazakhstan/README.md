## Почему этот материал

В проверенном GSC-срезе за 25–26.09 запрос «карта золота вко» имел 2 показа и 0 кликов. Это реальный сигнал, но слишком малая выборка для прогноза трафика. Связанные формулировки Wordstat по Казахстану: «карта золота казахстан» — 97, «карта месторождений казахстана» — 102; широкое соответствие, строки пересекаются. Данные уже сохранены в `docs/visibility/2026-09-29-wordstat-trends-evidence.md`, новые частотности для EN/KZ/ZH не выдумываем.

Страница отвечает на отдельный региональный вопрос: как сопоставить историческую ВКО с нынешней областью Абай, подобрать материалы в ЕПН и не спутать геологическую информацию с правом на работы. Общий гайд карт и новый due-diligence checklist остаются отдельными задачами, связанными ссылками.
