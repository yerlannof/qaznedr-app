## Вывод ведущего для сцены

Причина исходного дефекта подтверждена браузером: внутри каждого третьего отрезка скролла объект не двигался, затем CSS transition на 1 секунду продолжал анимацию после остановки. На узком desktop текст дополнительно менял высоту. Исправление сохраняет три утверждённые позы, интерполирует их напрямую и резервирует размер текста. Код чужих проектов и их изображения не скопированы; новые зависимости не добавлены.

Для нового внешнего вида одних библиотек недостаточно. Предложение 09: единая перспектива и вертикальная ось объекта, контролируемые промежутки между слоями, подписи с привязкой к рисунку, небольшая точная отметка зоны вместо большой рамки. Сцена остаётся условной геологической иллюстрацией. Новая графика и композиция требуют показа владельцу; исправление рывков в утверждённом варианте можно выпустить независимо.

## Проверка качества

- Измерять положение внутри этапов и одинаковые координаты при обратной прокрутке.
- После остановки скролла слой не должен догонять цель по таймеру.
- Заголовок/кнопки не скачут при смене пояснения; inactive текст скрыт от accessibility tree.
- Проверять маленький ноутбук, мобильные кнопки, no-JS, reduced motion, смену языка и вход/выход sticky-секции.
- Скорость оценивать на фактическом прототипе; название библиотеки и звёзды GitHub не доказывают производительность сайта.
