## B. Гайды

**B1. Отдельная дата проверки норм.**

- В `InsightEntry` появится поле `lawAsOf?: string` (ISO). Для `legal: true` оно обязательно. Юридическая плашка берёт `lawAsOf`, строка «Обновлено» по-прежнему берёт `updated`.
- Начальное значение `2026-09-26` у трёх юридических гайдов.
- Новый тест `registry-dates`:
  - каждая дата — реальная календарная `YYYY-MM-DD`;
  - `published ≤ updated`;
  - при `legal` поле `lawAsOf` есть и `published ≤ lawAsOf`;
  - дат в будущем нет.

## D. Надёжность

**D1. Ограничитель попыток (`src/lib/inquiries/throttle.ts`).**

- Сейчас при `> 5000` ключей делается `hits.clear()`, и это сбрасывает блокировку входа в админку.
- Новое поведение: сначала удаляются ключи, все отметки которых вне окна. Если ключей всё ещё больше предела, удаляются самые старые по порядку вставки, пока их не станет ровно столько, сколько разрешено.
- Предел становится параметром `maxKeys` (по умолчанию 5000).
- Тесты:
  - при переполнении устаревшими ключами заблокированный свежий ключ остаётся заблокированным;
  - размер не превышает `maxKeys`.

**D2. `formatCheckDate`.**

- День проверяется по реальному календарю, с учётом месяца и високосного года.
- При некорректном дне («00», 31.02) показывается месяц из того же значения (`06.2026`), без дня.
- При некорректном месяце — как раньше, месяц общей сверки.
- Тесты.

**D3. Счётчик участков и областей на главной.**

- `PortalWelcomeHero` просит `limit=100`, API режет до 50.
- Новая `src/lib/leads/stats.ts` → `collectLeadStats(fetchPage)`: берёт страницу 1 (`limit=50`), при `total > 50` догружает остальные страницы параллельно и считает уникальные области через `leadRegionName`.
- Тест с поддельным `fetchPage`: 2 страницы, дубли областей.
