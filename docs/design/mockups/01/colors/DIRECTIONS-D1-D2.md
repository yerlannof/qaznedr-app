# D1 / D2 — цвет и визуальный язык

Дата: 2026-09-26. Новые предложения после замечания владельца о шаблонности предыдущей подачи. Форма A3 «Контур» сохраняется. Владелец выбрал D2 «Сланец / сера» как рабочее цветовое направление; D1 не выбран.

## D1 — Малахит / киноварь

- Основа: малахит `#113F38`, минеральный белый `#F3F0E7`.
- Небольшой сигнальный акцент: киноварь `#B8422C` (ориентир до 8% площади).
- Нейтральный текст: `#242A27`.
- Характер: геологический архив, редакционная композиция, абстрактный графический шлиф породы, индексная полоса.
- Для сайта: минеральный светлый фон, малахитовая типографика и крупные поля, киноварь для небольших указателей/акцентов. На тёмном — светлый текст. Киноварь не использовать как мелкий текст по малахиту.

## D2 — Сланец / сера

- Основа: сланец `#253740`, мел `#E9ECE6`.
- Акцент: серно-жёлтый `#DDE55E` (ориентир около 10% площади).
- Характер: полевые исследования и точные инструменты, авторская графика керна, контрастные вертикальные метки.
- Для сайта: светлые читаемые контентные поля и сланцевые разделы; серно-жёлтая кнопка с тёмным текстом. Не использовать жёлтый как текст на светлом фоне.

## Решение владельца — 2026-09-26

Выбран D2 «Сланец / сера». Рабочая точная палитра: slate `#253740`, chalk `#E9ECE6`, sulphur `#DDE55E`; основная подача — [d2-slate-sulphur.png](d2-slate-sulphur.png). Направление формы A3 «Контур» сохраняется.
