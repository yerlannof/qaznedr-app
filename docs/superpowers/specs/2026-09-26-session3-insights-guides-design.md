# Сессия 3: раздел `/insights` и 4 гайда

Дата: 2026-09-26. Статус: дизайн одобрен владельцем в чате. Основа: спецификация перехода `2026-09-26-qaznedr-holding-pivot-design.md` §4, §6.2 и `docs/HOLDING_ROADMAP.md`, сессия 3.

## 1. Цель и критерии готовности

**Зачем.** Иностранный инвестор, чаще китайский, ищет «как получить лицензию в Казахстане», «哈萨克斯坦 探矿权», «GKZ vs JORC». Сейчас на такие запросы сайту нечего показать. Гайды дают поисковый трафик и цитирование в ИИ-ответах, а ещё показывают экспертизу холдинга. В каждом гайде есть ссылки на участки и контакты.

**Что сейчас.** `/blog`, `/education`, `/knowledge`, `/news` — клиентские страницы с выдуманным содержимым: «новости» со ссылками на министерства, просмотры, рейтинги, вебинары. Страниц статей нет. Для образа надёжного эксперта это вредно.

**Готово, когда:**

- `/{ru,en,zh}/insights` и 4 гайда × 3 языка отдают 200 на проде, есть в sitemap с верными hreflang, пинг IndexNow принят.
- `/{l}/blog|education|knowledge|news` (и вложенные пути) отдают 308 на `/{l}/insights`, их код удалён.
- JSON-LD `Article` и `BreadcrumbList` на статьях, `FAQPage` на FAQ для ru, en и zh — валидный JSON с нужными полями.
- FAQ на en и zh. В меню «Гайды» вместо «Блога». Есть ссылки из FAQ, `/services/legal` и тизера участка.
- build, lint и новые тесты зелёные. Новых падений в старых наборах нет.

**Решения владельца (2026-09-26):**

- zh публикуем сразу, вычитку переводчиком делаем параллельно. Для него готовим список zh-файлов.
- Юридические гайды (1, 4) публикуем до консультации юриста. Условия: только по тексту закона со ссылками на adilet.zan.kz, дата «по состоянию на», плашка «не юридическая консультация». Где норма читается неоднозначно, так и пишем: «уточняйте у юриста».

## 2. Хранение контента

Markdown-файлы, разбор библиотекой `marked`: одна новая зависимость, без своих зависимостей, умеет GFM-таблицы.

```
content/insights/
  <slug>/
    ru.md
    en.md
    zh.md
```

Шапка файла (front matter) — простые пары `ключ: значение` между строками `---`:

```
---
title: Заголовок H1 и <title>
description: 140–160 символов, для meta description и лида
updated: 2026-09-26
legal: true            # необязательно: включает юридическую плашку
---
```

- Шапку разбирает свой маленький парсер `parseFrontMatter` без зависимостей, покрытый тестом. Кавычки и многострочные значения не поддерживаются: они не нужны.
- Порядок статей, дата публикации и категория хранятся в реестре `src/lib/insights/registry.ts`: `{ slug, published, category }[]`. Реестр — единый источник для списка, sitemap и тестов.
- Загрузчик `src/lib/insights/content.ts` (только на сервере, `fs`):
  - `getArticle(slug, locale)` → `{ meta, html, readingMinutes } | null`;
  - `articleLocales(slug)` → языки, для которых есть файл;
  - `listArticles(locale)` → карточки для списка. Если перевода нет, берётся ru-версия со ссылкой на `/ru/…`.
- Время чтения: слова / 200 для ru и en, знаки / 400 для zh. Минимум 1 минута.
- `marked` рендерит HTML на этапе сборки, на клиент библиотека не уходит. Контент наш, из репозитория, поэтому санитизация не нужна.
- В тексте ссылки на свои страницы пишутся абсолютными путями с языком: `/zh/leads`, `/zh/contact`.
- Страницы собираются статически: `generateStaticParams` по реестру × языкам, `dynamicParams = false`.
- Файлы `content/` добавляются в `outputFileTracingIncludes`, если того потребует сборка. Проверяется в плане.

## 3. Маршруты и редиректы

| URL                    | Что                                                                                     |
| ---------------------- | --------------------------------------------------------------------------------------- |
| `/{l}/insights`        | Список гайдов (RSC). kz показывает ru-статьи со ссылками прямо на `/ru/insights/<slug>` |
| `/{l}/insights/<slug>` | Статья. Если файла для языка нет → `permanentRedirect` (308) на `/ru/insights/<slug>`   |

- Адреса статей английские и одинаковые на всех языках. Переключатель языка в футере сохраняет путь, поэтому kz-адрес статьи уводит на ru, а не на 404.
- В `HIDDEN_ROUTE_REDIRECTS` добавляются `/blog`, `/education`, `/knowledge`, `/news` → `/insights`.
- Папки `src/app/[locale]/{blog,education,knowledge,news}` удаляются: это выдуманное содержимое, а не рабочая функция.
- В `PUBLIC_PAGES` четыре старых пути заменяются на `/insights`.
- Страницы статей добавляются в sitemap отдельно, как участки: только существующие языки, hreflang только на них + x-default → ru.
- Переводы `seo.blog|education|knowledge|news` и `navigation.blog|education|knowledge|news` удаляются, если после удаления страниц на них нет ссылок. Появляются `seo.insights` и `navigation.insights`.

- Карточки: категория, заголовок (h2), описание, «Обновлено» и время чтения.

**Статья:**

  - h2 и h3 в serif;

- В конце каждой статьи — раздел «Источники» (часть markdown) и блок CTA: «Смотреть участки» → `/{l}/leads`, «Связаться» → `/{l}/contact`.
- Затем «Другие гайды»: остальные статьи на этом языке.
- Один H1. В markdown заголовки начинаются с `##`, тест проверяет, что `# ` в теле нет.

## 5. SEO

- `buildPageMetadata` получает необязательные поля:
  - `locales?: Locale[]` — hreflang только на эти языки;
  - `article?: { published, modified }` → `openGraph.type = 'article'`, `publishedTime`, `modifiedTime`.
- JSON-LD `Article`: `headline`, `description`, `inLanguage` (HREFLANG), `datePublished`, `dateModified`, `mainEntityOfPage`, `isAccessibleForFree: true`, `author` и `publisher` = `Organization` «QAZNEDR HOLDING» с `url` `https://qaznedr.kz`. Плюс `BreadcrumbList`.
- Список получает `BreadcrumbList`.
- Помощник `src/lib/seo/article-jsonld.ts`, по образцу `lead-jsonld.ts`.
- `public/llms.txt`: раздел «Guides» — 4 гайда × en/zh/ru.

## 8. Содержание гайдов

Общие правила для всех 12 файлов:

- **Факты** — только из первоисточников. Для права: Кодекс РК «О недрах и недропользовании» (К1700000125), Закон № 337-VIII от 07.07.2026, подзаконные акты на adilet.zan.kz. Для стандартов: GB/T 17766-2020, кодексы KAZRC и JORC 2012, шаблон CRIRSCO. Номера статей и цифры (сроки, площади, бонусы) сверяются с текстом нормы. Если не удалось проверить — не пишем.
- **Раздел «Источники»** со ссылками на документы.
- **Красные линии** (спецификация перехода §3, память `feedback-lead-copy-rules`):
  - не писать и не намекать, что участки наши;
  - не писать, что продаём отчёты или данные;
  - не обещать гарантированной доходности;
  - ГКЗ C1/C2 не называть JORC, P1–P3 — прогноз, а не запасы;
  - «свободен» — по нашей проверке на дату;
  - не обещать, что лицензия будет получена: решает государство, мы сопровождаем;
  - без OCR, ИИ и моделей;
  - слово «портфель» не используем (старый тест запрещает его на публичных страницах) — пишем «участки», «витрина».
- **Язык:** ru — оригинал, en и zh — перевод. Термины zh: 矿业权, 探矿权, 采矿权, 勘查许可证, 资源量, 储量, 品位, 金属量, 股权转让, 矿业权转让. В title и H1 на zh — 哈萨克斯坦. Тон короткий и фактический, без маркетингового шума.
- **Объём:** 1 200–2 000 слов на ru, в начале — абзац с прямым ответом (для ИИ-цитирования).

**Каркас гайдов:**

1. **Как иностранному инвестору получить право недропользования в Казахстане (2026)**, `legal: true`, категория «Право».
   - Кто может быть недропользователем, в том числе иностранные юрлица.
   - Три пути: новая лицензия, приобретение права или доли, СП / earn-in.
   - Что учесть: разрешение на переход, приоритетное право государства там, где применимо, сроки.
   - Чем помогает холдинг: подбор участка, сопровождение заявки, due diligence.
2. **Лицензия на разведку ТПИ: процесс по шагам**, `legal: true`, категория «Лицензирование».
   - Принцип очерёдности заявлений (если подтвердится по тексту Кодекса) и где подаётся заявление.
   - Блоки и предельная площадь, срок и продление.
   - Подписной бонус, минимальные расходы, обязательства.
   - Переход к добыче. Таблица «шаг — срок — документ».
3. **Классификации запасов: ГКЗ ↔ KAZRC/JORC ↔ GB/T 17766-2020**, категория «Геология».
   - Сводная таблица категорий с оговоркой: соответствие приблизительное, прямого пересчёта нет.
   - Что такое «историческая оценка» и почему советские C1/C2 нельзя называть JORC без работы компетентного лица.
   - Как холдинг указывает стандарт в тизерах.
4. **Сделки с правом недропользования: разрешение на переход и изменения 2026 года**, `legal: true`, категория «Право».
   - Какие сделки требуют разрешения (ст. 44–45), запрет передачи лицензии на разведку в первый год.
   - Что изменил Закон 337-VIII с 07.09.2026 (и с 01.01.2027) — по тексту закона и опубликованным разборам.
   - Последствия сделки без разрешения, практические шаги.

## 9. Защита текстов (тесты)

`src/__tests__/lib/insights/*.test.ts`:

- `parseFrontMatter` разбирает шапку и отвергает файл без неё.
- Для каждой статьи реестра есть ru, en и zh. В шапке заполнены `title`, `description` и `updated` (ISO-дата). В теле нет `# ` (H1). Есть раздел источников («## Источники» / «## Sources» / «## 参考资料»).
- В markdown нет запрещённых формулировок:
  - гарантированн* доходност*, guaranteed return, 保证收益;
  - продаём/продаем отчёт\*, sell reports;
  - OCR, нейросет\*, ИИ-, AI model;
  - портфел\*, portfolio, 投资组合;
  - маркетплейс, marketplace;
  - obtain the licen[cs]e.
- Внутренние ссылки `/(ru|en|zh|kz)/…` в markdown не ведут на скрытые маршруты (`hiddenRouteRedirect`).
- `hiddenRouteRedirect('/ru/blog/x') === '/ru/insights'` — и так для каждого из 4 разделов.
- В sitemap есть `/insights` и статьи. У статьи hreflang только ru, en, zh и x-default.
- `no-hidden-links.test.ts` сканирует новые страницы, потому что `/insights` попадает в `PUBLIC_PAGES`.

- Работаем в `master` в `~/Documents/qaznedr-app`. Файлы добавляются поимённо, `docs/design/` (работа Codex) не трогаем.
