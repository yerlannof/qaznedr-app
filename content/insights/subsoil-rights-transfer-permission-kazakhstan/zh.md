在哈萨克斯坦，底土利用权的转让，以及底土利用人及其控制公司的股权和股票的转让，须取得主管机关的许可（《底土与底土利用法典》（简称《底土法》）第44条），但该条第2款规定的例外情形除外。固体矿产勘查许可证在有效期的第一年内不得转让（第40条）。自2026年9月7日起，根据第337-VIII号法律，收购股权或股票后买方持股比例低于25%的（此前为低于1%），无需取得许可；同时，未经许可的交易不再是自始无效的交易，而改为可由法院根据主管机关的起诉宣告无效。本文依据截至2026年9月26日的法律条文编写，不构成法律意见。

## 哪些交易需要许可

以下两种情形须取得主管机关的许可（第44条第1款）：

- **底土利用权或其中份额的转让**——包括依据合同、固体矿产勘查许可证或开采许可证、底土空间使用许可证享有的权利；
- **与底土利用权相关的客体的转让。**即作为底土利用人的法人的股权、份额、股票以及可转换为上述权益的有价证券，也包括控制链上层任何直接或间接决定其决策的公司的上述权益（第41条第1款）。在有组织市场或外国证券交易所流通的证券不属于此类客体（第41条第2款）。

客体的转让不仅包括出售，还包括赠与、向注册资本出资、强制执行（包括对质押物的强制执行）、吸收新参与人、重组以及上市（第42条第1款）。依法院（仲裁庭）裁决以及在其他不取决于双方意志的情形下发生的所有人变更，不视为转让（第42条第3款）。

在固体矿产开采许可证申请审查过程中，收到设计文件须经专家审查之通知的公司，也视同底土利用人（第44条第3款第3项）。

主管机关由政府确定（第60条）。转让许可申请由买方提交（第45条第1款）。如转让的是底土利用权本身，交易完成后，双方须向原发证机关共同申请办理许可证变更登记（第40条第3款）。

### 无需许可的情形

例外情形列于第44条第2款。对投资者而言，主要包括：

| 情形                                                                                                    | 条款                        |
| ------------------------------------------------------------------------------------------------------- | --------------------------- |
| 持股不低于99%的集团内部转让（子公司、母公司、同一所有人名下的公司），且受让方未在实行优惠税制的国家注册 | 第44条第2款第1–4项          |
| 股权、份额或股票转让后，买方持股比例低于25%                                                             | 第44条第2款第5项            |
| 注册资本发生变动，但各参与人的持股比例不变                                                              | 第44条第2款第6项            |
| 一方为政府、国家机关、国家管理控股公司或国家公司                                                        | 第44条第2款第7项            |
| 法人组织形式变更、继承、发行人回购自身股票、强制重组                                                    | 第44条第2款第9–11项、第15项 |
| 无表决权、且无参与管理权的股票及其他证券的转让                                                          | 第44条第2款第16项           |

25%的门槛仅适用于股权、份额和股票。对于底土利用权本身的份额——即买方成为许可证共同持有人的情形——不存在此项例外。连续进行多笔交易或通过关联方收购时如何计算该门槛，条文未作明确规定，请咨询律师。

## 哪些转让被禁止

以下情形禁止转让底土利用权或其中份额（第40条第2款）：

- 固体矿产勘查许可证有效期的第一年内；
- 底土地质研究许可证；
- 个体小规模采矿许可证；
- 油气勘探开采合同的前三年内，《底土法》规定的情形除外。

对于油气合同，如该合同是公司唯一的合同，前三年内其股权和股票的转让同样被禁止（第42条第2-1款）。对于固体矿产勘查许可证，第42条并未直接禁止在第一年内转让股权，但如交易不属于例外情形，仍须依第44条取得许可。主管机关将如何审查此类交易，无法从条文中得出，请咨询律师。禁止将底土利用权交付信托管理，法律明确规定的情形除外（第48条第2款）。

## 国家优先购买权

国家有权优先购买拟转让的底土利用权、其中份额或相关客体，但仅限于战略性底土区块（第43条第1款）。《底土法》将以下区块认定为战略性区块（第43条第2款）：

- 石油地质储量超过5000万吨或天然气地质储量超过150亿立方米；
- 位于里海哈萨克斯坦海域；
- 含铀矿床，包括稀土-铀矿床。

不含铀的陆上金属矿区块——金、铜、多金属——按照第43条的文字，不符合上述标准。国家优先购买权不适用于第44条第2款所列例外情形中的交易（第43条第3款）。

如属战略性区块，国家优先购买权与转让许可申请一并审查。申请中须注明价格和付款方式（第45条第4款），且在3个月内不得撤回或变更（第46条第2款）。国家通过国家管理控股公司或国家公司，按不低于申请所载价格、不劣于申请所载条件的标准购买；无偿转让或向注册资本出资的，按市场价格购买（第46条第3–4款）。

## 申请与审查时限

申请中须载明（第45条第2款）：

- 受让方信息；如为法人，还包括直接或间接决定其决策的个人、组织和国家的信息；
- 拟取得的具体标的及取得依据；
- 涉及油气和铀的，受让方的财务和技术能力；
- 所提供信息真实性的确认以及签署人信息。

申请须附哈萨克语和俄语的证明文件原件或公证副本。外国公司的文件可以使用其他语言，但须附经公证的哈萨克语和俄语译文（第45条第5款）。

| 阶段                             | 时限                                               | 条款         |
| -------------------------------- | -------------------------------------------------- | ------------ |
| 将申请转交底土利用问题专家委员会 | 5个工作日                                          | 第45条第6款  |
| 专家委员会审查                   | 最长15个工作日；大型矿床和战略性区块最长45个工作日 | 第45条第6款  |
| 根据专家委员会建议作出决定       | 5个工作日                                          | 第45条第6款  |
| 审查总时限                       | 1个月；大型矿床和战略性区块为3个月                 | 第45条第6款  |
| 转让许可有效期                   | 1年                                                | 第45条第13款 |
| 权利转让后办理许可证变更登记     | 自申请之日起7个工作日                              | 第40条第3款  |
| 取得股权和股票后的通知           | 不迟于1个月                                        | 第42条第2款  |
| 底土利用人控制权变更的通知       | 30个日历日                                         | 第47条第1款  |

如要求补充文件，时限中止计算，直至文件提交（第45条第6款）。如区块包含固体矿产大型矿床、属于战略性区块，或交易涉及国家安全，相关文件须在5个工作日内送交国家安全机关。如国家安全机关在10个工作日内告知交易涉及国家安全利益，审查即中止，直至确认符合要求（第45条第7款）。《底土法》所称大型矿床，例如资源量超过250吨的金矿床、超过500万吨的铜矿床（第14条第3款）。

第47条所称控制，特别是指持有超过25%的股权、表决权或可分配净收入，或依据合同有权决定其决策（第47条第5款）。

交易有下列情形之一的，拒绝发放转让许可（第45条第10款）：

- 威胁国家安全，包括导致底土利用权集中；
- 导致合同项下的权利集中；
- 为《底土法》所禁止，或违反哈萨克斯坦缔结的国际条约；
- 涉及因行政处罚而被禁止作业的区块。

申请不符合《底土法》规定或国家行使优先购买权时，同样拒绝发放许可。底土利用权集中，是指同一人或来自同一国家的一组人合计持有的份额可能对国家安全构成威胁。以国家安全为由的拒绝不说明理由；任何拒绝均可向法院起诉（第45条第11款）。

转让许可中载明受让方以及拟转让份额的上限（第45条第12款）。如交易条件与许可不一致，将拒绝办理许可证变更登记（第40条第4款第2项）。

## 未经许可交易的后果

- 未经许可或在许可期满后进行的交易，可由法院根据主管机关的起诉宣告无效（第44条第4款，2026年9月7日起施行的版本）。
- 需要许可而未取得的，不予办理许可证变更登记（第40条第4款第3项）。
- 如违反第44条第1款导致国家安全受到威胁，固体矿产勘查许可证或开采许可证将被撤销（第200条第1款第1项、第221条第3款第1项）。

第337-VIII号法律未就2026年9月7日前完成的交易作出过渡性规定。此类交易适用哪一版本的第44条第4款，请咨询律师。

## 2026年9月7日起的变化（第337-VIII号法律）

2026年7月7日第337-VIII号法律自首次正式公布之日起满60个日历日后施行（第2条）；据Paragraph法律信息系统，施行日期为2026年9月7日。下表仅列出已对照法律和《底土法》原文核实的条款。

| 《底土法》条款                                  | 2026年9月7日前                           | 2026年9月7日起                                                                                                                                                                                                         |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 第44条第2款第5项                                | 买方成为不足1%的持有人时，无需许可       | 门槛改为低于25%                                                                                                                                                                                                        |
| 第44条第2款第16项                               | 无此规定                                 | 无表决权、且无参与管理权的证券转让无需许可。如被动投资者取得控制权，包括取得超过25%净收入的权利，须依第47条进行通知                                                                                                    |
| 第44条第4款                                     | 未经许可或在许可期满后进行的交易自始无效 | 可由法院根据主管机关的起诉宣告无效                                                                                                                                                                                     |
| 第42条第3款                                     | 依法院裁决变更所有人不视为转让           | 增加仲裁：“法院（仲裁庭）”                                                                                                                                                                                             |
| 第41条第1款、第45条第2款第4项、第40条第3款      | 铀的相关规则适用于开采合同               | 扩展至铀勘查                                                                                                                                                                                                           |
| 第28-2章（第221-6—221-9条）、第70条第3款第1-1项 | 无此规定                                 | 固体矿产（铀和煤炭除外）的拍卖区域可为国家公司预留，期限最长3年。国家公司由此取得的权利禁止转让，但转让给合资企业的除外：国家公司在该合资企业中持股不低于30%并拥有控制权，且战略合作伙伴已承担投资、技术转让和融资义务 |

### 2027年1月1日起施行的内容

根据该法第2条，自2027年1月1日起仅施行一项规定：删除《底土法》第178条第3款。该款规定，铀矿底土利用人在培训、科研和地区发展方面的超额支出可计入下一年度。该规定与转让许可无关。

### 未能核实的事项

- 2026年9月7日后，相关下位法规是否已更新：专家委员会条例、国家优先购买权审查程序、第47条规定的通知格式。
- 第44条新规如何适用于2026年9月7日前签署的交易，以及被动投资者的控制权如何认定：目前尚无实践，请咨询律师。

## 交易前核对清单

1. 确定交易标的：是底土利用权本身（办理许可证变更登记，第40条），还是股权和股票（第41–42条）。所需文件和通知取决于此。
2. 核查勘查许可证的颁发日期：是否仍处于有效期第一年内。
3. 计算买方最终持股比例，并梳理直至最终所有人的控制链；核查第44条第2款的例外情形。
4. 核查区块是否属于战略性区块（第43条）、是否为大型矿床（第14条）：这决定审查时限、国家安全审查以及国家优先购买权问题。
5. 核查权利负担和同意事项：质押（须取得质权人书面同意）、权利共有人、区块上的行政禁令（第40条第3款和第4款）。
6. 在时间表中为审查预留1–3个月，另加补充文件要求所需时间；转让许可有效期为1年。
7. 与律师共同在合同中约定“交割前取得转让许可”这一条件及许可被拒绝的后果。
8. 交割后：办理许可证变更登记，并依第42条和第47条进行通知。
9. 如交易涉及国家公司，须对照第28-2章核对交易条件。
