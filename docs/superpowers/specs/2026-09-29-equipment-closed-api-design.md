# Закрытая серверная часть объявлений

Продолжение утверждённого показа13 и domain-модуля, команда владельца «давай дальше»29.09.2026. Публичный UI не меняется.

## Объём этого выпуска

- Серверный флаг `EQUIPMENT_MARKETPLACE_ENABLED` по умолчанию выключен, значение только `true` включает тестовый доступ. На проде флаг не включаем.
- Отдельные API владельца: список, черновик, просмотр, изменение, отправка на проверку, архив. И отдельные API администратора: очередь и решение модерации.
- NextAuth из действующего auth.config; ID только из серверной сессии, роль проверяется requireAdmin. Ответы private/no-store и noindex. Запись требует same-origin JSON; ограниченный размер тела, неизвестные поля отклоняются. Нет клиентского owner/status/admin.
- Каждая запись требует expectedRevision; БД сравнивает revision/owner/status атомарно и записывает событие модерации в той же транзакции. Stale возвращает409, чужое объявление404.
- Новая equipment-таблица закрыта RLS и GRANT: anon/authenticated не читают ни строки, ни приватные колонки. Публичного API пока нет. Service role остаётся только на сервере.
- Legacy POST регистрации закрывается404 без чтения тела/Prisma/базы. Его прежний first-user super_admin путь удаляется. Существующий вход владельца сохраняется. Новый процесс идентификации и регистрации будет отдельным выпуском после выбора входа; не подменяем его публичной регистрацией по паролю.
- Миграция проверяется на отдельной локальной БД с синтетическими данными. В production её пока не применяем: закрытый код не требует новой таблицы при выключенном флаге.

## Границы готовности

Данный выпуск — работающий и проверяемый серверный слой под закрытым флагом, не запуск площадки. Нет фото/uploads, новой регистрации, UI кабинета, реальных объявлений, изменения геобазы, удаления308 или индексации каталогов. Следом — согласованный вход, безопасные фото, форма и модераторский экран.
