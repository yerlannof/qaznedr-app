## Закрытый этап каталога

Подготовлены owner-only GET/POST фотографий и чтение обработанного WebP.
Все ответы private/no-store/noindex, default-off404 до auth/Storage.
JPEG/PNG/WebP до3MiB; фактическая сигнатура и декодирование, до24млн пикселей,
ориентация EXIF, удаление метаданных,1600×1600 без увеличения, отказ анимации/SVG.
Фотография проходит атомарную проверку владельца/ревизии/статуса/лимита8 в SQL;
изменение ACTIVE возвращает объявление на модерацию и отменяет старое решение.
Бакет приватный, restrictive RLS закрывает browser-доступ даже при чужой широкой
permissive policy. Пути и данные владельца не выходят в HTTP-ответ.

Независимое ревью нашло гонку cleanup при неизвестном исходе RPC. Исправлено
через red/green: удаление только после подтверждённого SQL rollback и отсутствия
attachment; transport error/невалидный ответ сохраняют приватный объект для
сверки. Реальный APNG без metadata.pages также отклоняется по PNG-chunks.

Миграция **не применялась в production**, флаги/Google/регистрация не включались.
До публичного запуска нужны живой Supabase Storage/HTTP lifecycle, квоты аккаунта,
очистка orphan-объектов и retention, удаление/порядок фото, безопасный preview для
