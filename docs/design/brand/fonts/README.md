# Предложение наборной типографики

Source Serif 4 Display Regular — крупные латинские/кириллические заголовки; Source Serif 4 Regular — редакционные акценты. IBM Plex Sans Regular/SemiBold — интерфейс и основной текст. Это предложение к утверждению, не изменение ранее выбранного характера логотипа. Логотип имеет отдельный векторный рисунок букв.

中文: системный стек `PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans CJK SC, sans-serif`, без разрядки. Китайские гарнитуры сюда не скопированы. Шрифты RU/EN загружаются локально; внешних запросов к Google Fonts нет.

Файлы скачаны из официальных репозиториев, лицензии сохранены рядом. Исходники, фактический вес и SHA-256 записаны в `sources.json`.

- [Adobe Source Serif](https://github.com/adobe-fonts/source-serif/tree/release) — [лицензия OFL](https://github.com/adobe-fonts/source-serif/blob/release/LICENSE.md).
- [IBM Plex](https://github.com/IBM/plex) — [лицензия OFL](https://github.com/IBM/plex/blob/master/LICENSE.txt).

Проверена таблица символов загруженных TTF: латинское название, русский текст и казахские Ә Ғ Қ Ң Ө Ұ Ү Һ І присутствуют. Это проверка наличия символов, не утверждение готового казахского перевода. Исходные TTF удобны для документов. Для сайта использовать WOFF2 и сохранять лицензии; самостоятельное размещение не требует установки шрифтов в систему.
