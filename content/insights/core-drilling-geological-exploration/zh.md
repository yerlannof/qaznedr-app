岩芯钻探可以从钻孔中取得岩芯，也就是一段圆柱形岩石。岩芯有助于研究地下岩石的种类、排列顺序和特征。但仅有一箱岩芯，还不能回答一片区域有多少金属。还需要知道样品对应的深度，查看地质描述、取样记录和化验结果。

本指南面向正在查看哈萨克斯坦勘查区资料，或准备讨论下一步工作的人。它帮助您理解术语，并向地质学家提出具体问题。这里讨论矿产勘查；为供水选择水井是另一项任务。

## 什么是岩芯？它与钻屑有何区别？

岩芯钻探使用工具取得圆柱形的岩石样品。保存完好的岩芯有助于研究岩石随深度如何变化。[美国地质调查局（USGS）](https://www.usgs.gov/core-research-center/about)也这样说明岩芯的用途。

钻屑是钻探过程中从钻孔带出的细小岩石碎屑。钻屑同样提供地质信息，但保存的岩石结构细节少于岩芯。钻探方法应根据任务和场地条件选择；没有适用于所有项目的单一方法。

## 钻探资料中应查看什么？

如果知道岩芯照片对应哪一个钻孔、哪一段深度，照片才更有用。[2012年版JORC规范的表1](https://www.jorc.org/docs/JORC_code_2012.pdf)列出了钻探方法、样品采取率、岩石记录、取样和化验质量等信息。初次讨论时，可以准备以下资料：

| 资料                                   | 有助于核查什么                       |
| -------------------------------------- | ------------------------------------ |
| 标有坐标和坐标系统的钻孔位置图         | 工作在哪里进行，是否涉及关注的区域   |
| 钻孔深度、倾角和方向资料               | 钻孔如何穿过所研究的岩石             |
| 标有钻孔编号和深度区间的地质记录及照片 | 地质学家观察到什么，记录对应哪个深度 |
| 岩芯采取率数据                         | 已钻进区间中实际取得多少岩芯         |
| 样品清单和实验室报告                   | 样品、深度区间与化验结果如何对应     |
| 分析方法和质量控制资料                 | 报告中的数值经过哪些核查             |

这是一份起步清单，不是完整的审查方案。这里引用JORC，是把它作为数据核查问题的参考资料。表1不会使这些资料自动成为JORC报告，也不为哈萨克斯坦所有项目设定必须遵守的规则。

## 岩芯采取率为什么重要？

岩芯采取率表示已钻进区间中，有多少部分被取出的岩芯所代表。如果部分岩石丢失，地质学家需要评估这会如何影响地质描述，以及样品是否具有代表性。不同材料的损失程度可能不同，因此不能脱离岩石性质和取样条件，单看一个百分比。

特别是，JORC建议检查样品采取率与有用组分品位之间是否可能存在关联。本指南不规定适用于所有任务的“足够高的百分比”；需要根据具体资料判断。

## 看岩芯能知道是否有黄金吗？

地质描述可以帮助找出值得关注的深度区间。要确定黄金品位，需要合适的取样、化验和质量控制。照片中的岩石颜色或可见的闪亮颗粒，本身不能确定金属品位。

即使单个样品的结果很好，也不能把它推及整个区域。需要了解取样区间的位置和长度、邻近样品的结果以及地质背景。关于勘查结果、资源量和储量的区别，请阅读[另一篇指南](/zh/insights/reserve-classification-gkz-kazrc-jorc-gbt17766)。

还有一个重要问题：沿钻孔测得的矿化交段长度，可能不同于矿体的真实厚度。如果尚未确定矿体的几何形态，就不能自动把交段长度称为矿体厚度。

## 讨论新工作前应准备什么？

先明确目的：检验某个地质假设、弄清区域的地质构造，还是理解以往结果。然后收集已有的地图、报告和旧钻孔资料，列出缺少的信息。[地质资料核查清单](/zh/insights/geological-due-diligence-kazakhstan)可以帮助您整理。

初次联系时，说明地区、目的和已有资料即可。钻孔深度、数量、钻探方法和取样安排，应依据原始资料讨论。单一的每米报价无法说明全部地质工作的范围；还需分别确认报价包含什么、样品如何记录，以及将向客户交付哪些结果。

区域的矿业权问题应单独考虑。[勘查许可证指南](/zh/insights/solid-minerals-exploration-licence-kazakhstan)提供初步信息。
