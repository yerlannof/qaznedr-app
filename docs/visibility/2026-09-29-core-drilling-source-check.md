1. USGS Core Research Center, About: https://www.usgs.gov/core-research-center/about — получен HTTP 200 через Firecrawl 29.09.2026. Подтверждает: керн — цилиндр породы, извлечённый полым буровым инструментом; показывает последовательность пород; cuttings — мелкие обломки, несущие меньше структурных деталей. В публичный текст не переносим американские количественные оценки стоимости и размера коллекции.
2. JORC Code **2012 edition**, https://www.jorc.org/docs/JORC_code_2012.pdf — получен HTTP 200, извлечены 44 страницы. Проверены Table 1 Sections 1–2: drilling techniques; drill sample recovery; logging; sub-sampling; assay quality; sample verification; location; drill-hole information; intercept length versus true width. Ссылка на конкретную редакцию, без заявления, что это действующая обязательная норма Казахстана. Не утверждаем текущий статус всего стандарта или соответствие статьи JORC.
