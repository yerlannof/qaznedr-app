# D2 — масштаб, детали и международная типографика

Дата: 2026-09-26. Статус: предложения на рассмотрении, продолжение ранних эскизов айдентики 01. Не утверждает макет главной или реализацию движения.

Владелец положительно оценил расширенные сцены и попросил ещё развить их. Отдельно напомнил о важности китайской и английской версий. Следующий раунд увеличивает саму иллюстрацию и глубину её рассмотрения: два крупных кадра вместо добавления мелких ячеек в раскадровку.

## Кадры

1. **От поверхности к глубине — 中文, тёмная тема.** Крупный условный разрез массива связывает рельеф, структуру и прожилок. Отделённая плоскость помогает прочитать внутреннее строение. Маленький образец связан с местом отбора. Это визуальная метафора изучения недр, а не изображение принадлежащего компании участка.
2. **От жилы к образцу — EN, светлая тема.** Камера приблизилась к структуре породы: видно соотношение вмещающей породы и светлой жилы. Выделенный образец связан с исходным фрагментом. Архив, поле и проверка показывают работу с источниками без вымышленных результатов анализа.

Кадры иллюстрируют две главы одной идеи, а не варианты на выбор по языку. Сравнение тёмной/светлой подачи и масштаба графики — предмет текущего обсуждения. В окончательной системе каждый кадр должен иметь обе локализации. Геологическая непрерывность между независимо сгенерированными картинками пока приблизительная: для движения потребуется единый согласованный объект и его слои.

## Набор и мобильная композиция

- Китайский: спокойный системный CJK sans, без разрядки между иероглифами и без подстановки латинской гарнитуры. На сайте использовать стек из BRIEF.md. Латиница: выбранный характер A3 в крупных заголовках, ясный sans для подписей.
- Для рабочего размера 375 px: боковые поля 20 px, полезная ширина 335 px; заголовок 中文 ориентировочно 30–34 px, английский 32–36 px, основной текст 16 px. Это стартовые размеры для будущей проверки, а не измеренные свойства изображений.
- Порядок: короткий заголовок → иллюстрация → максимум две поясняющие подписи → контакт. Выноски с широкого кадра на мобильном переходят под рисунок. Не уменьшать всю десктопную композицию до ширины телефона.
- Китайская короткая фраза и более длинный английский заголовок получают отдельные переносы. Контакт доступен без прохождения всей сцены. WeChat ID и копирование нужны рядом с QR: посетитель может смотреть сайт с того же телефона.
- Смысл не зависит от движения. На мобильном достаточно последовательных статичных глав и очень небольших смещений; без длинного закрепления экрана. Desktop-переход: общий план → разрез → приближение к жиле → связь с образцом → сопоставление источников. Для reduced motion — статичные главы.

### Проверка изображений

Оба изображения сохранены и просмотрены ведущим. Китайский кадр читается как крупный разрез массива, английский — как приближение к прожилку. Основные заголовки и смысловые подписи присутствуют. Это два разных условных объекта, не непрерывные кадры готовой анимации.

Для следующей доводки: в английском кадре подпись `Sample location` следует привязать к рамке на исходной породе, а отдельный фрагмент подписать `Sample`; жёлтые линии на светлом фоне сделать сланцевыми для лучшей различимости. Золотистые вкрапления сократить в обоих кадрах. В китайском CTA убрать избыточную разрядку. Текстовое имя в этих эскизах не является заменой утверждённого знака A3; при сборке вернуть единый мастер логотипа.
