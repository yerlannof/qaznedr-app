# Handoff: localization draft

Draft UI copy is taken from `../review/site-preview.html` locale strings and `../mockups/03/spec.md` through `../mockups/06/spec.md`. It is a design draft, not certified translation. A Chinese-language editor should review naturalness and a qualified geologist should review technical terms. No legal equivalence is asserted here.

## Working glossary

| English         | Русский                                    | 中文（简体）          | Note                                                             |
| --------------- | ------------------------------------------ | --------------------- | ---------------------------------------------------------------- |
| site / area     | участок                                    | 区域 / 项目           | Select by context; avoid wording that implies company ownership. |
| teaser          | тизер участка                              | 项目简介              | Initial information page; not a formal report.                   |
| archival report | фондовый отчёт                             | 档案报告              | Check preferred geological usage with editor.                    |
| grade / content | содержание                                 | 品位                  | Specify metric and source where relevant.                        |
| local high      | локальный пик / локальное высокое значение | 局部高值              | Never present as average.                                        |
| availability    | доступность                                | 可申请状态 / 可用状态 | Must be qualified by current verification.                       |
| after NDA       | после NDA                                  | 签署保密协议后        | Do not imply automatic document release.                         |
| due diligence   | комплексная проверка                       | 尽职调查              | Do not present categories across standards as equivalent.        |
| joint venture   | совместное предприятие                     | 合资合作              | Keep as possible format only when offered.                       |
| WeChat ID       | WeChat ID                                  | 微信号                | Use actual verified account only.                                |

The preview-form message applies only to the non-sending prototype. Production success/error copy must match the implemented delivery behavior. Any legal qualification, statutory reference, or equivalence between GKZ, KAZRC, JORC, or GB/T 17766 requires separate specialist review; this glossary does not translate or equate those rules.
