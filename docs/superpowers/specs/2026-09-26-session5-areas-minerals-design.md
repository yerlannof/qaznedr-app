# Сессия 5 — каталог, тизер, хабы металлов и чтение

Основа: утверждённые 04/06, A3/D2 и локальные шрифты сессии 4. Данные leads/lead_private не изменяются. Старые согласованные тексты и существующая локализация переиспользуются; новые геологические подписи требуют ответа владельца. Никаких рыночных прогнозов, выдуманных чисел и координат.

## Поведение

- Каталог /leads: серверная выдача, металл/регион/геологический тип + прежние сортировка/свободность; URL сохраняет фильтры при пагинации. Desktop строка фильтров, mobile Sheet с Escape/возвратом фокуса. Пустой результат со сбросом. Ошибка не считается пустым успехом.
- Металл: шесть стабильных направлений gold/copper/lead-zinc/molybdenum/tungsten/iron. Составные обозначения Au+Cu/Pb-Zn распознаются по символам; zinc/lead входит в общее направление. Не подменять тип геологии коммерческим tier. Неизвестные значения API по-прежнему допускают точный поиск.
- Карточки/тизер: заголовки en/zh/kz из уже переведённого leadSeoText, регион и тип локализованы, код остаётся. Исходные количественные данные и пояснения не перефразировать автоматически. Дата проверки рядом со статусом. Категории P1–P3 не называть запасами; стандарт не придумывать.
- Тизер: открытые параметры, NDA, контакты и резервная форма, форматы работы, проверка/юридическое примечание. Код сохраняется в каналах и форме; настоящих закрытых данных в DOM нет. Общие контактные компоненты получают D2 без изменения отправки.
- Хабы /minerals/[mineral]: шесть маршрутов, реальные связанные участки, краткий контекст из согласованных пояснений, ссылки на существующие гайды/FAQ и контакт. Пустой хаб честно показывает отсутствие опубликованных результатов. Метаданные/hreflang, CollectionPage/BreadcrumbList, sitemap, llms.txt, внутренние ссылки, IndexNow после deploy. Неизвестный slug — 404.
- Гайды/статьи: внедрить утверждённое оформление 06, сохраняя проверенные статьи, источники, даты и доступные таблицы. Не вводить неподтверждённые редакционные тексты.

## Проверка

TDD фильтрации мультиметалла и типа, сохранения URL, локализованного заголовка и даты, неизвестного хаба, SEO/public routes. Полный Jest относительно базы 4 (1431 passed/28 старых failures), ESLint, build. Browser375/1440 × четыре языка × обе темы: каталог/тизер/хаб/гайд, фильтры/reset/empty/paging, форма без отправки. Независимое ревью полного диффа, push master и Production.

## Внешние зависимости

Пакет 20–40 участков и переводы произвольных полей геобазы/подтверждение стандартов — у владельца и геологов. Без них публикуется только уже открытая выборка и её исходные значения, с явными пояснениями. Новые данные не генерируются.
