Дата: 2026-09-26. Независимое продолжение замечаний сессии 3б, пока дизайн 03–06 ожидает утверждения. Новую визуальную систему не внедряем.

## Результат

- Ошибка Supabase при чтении списка участков отличается от корректного пустого списка. API возвращает 503 без кэширования ошибки и без технических подробностей; следующий запрос повторяет чтение. Успешные ответы сохраняют TTL 60 секунд. Серверная страница использует существующую границу ошибки Next.
- Регионы таблиц гайда получают последовательные доступные имена на языке статьи; счёт начинается заново для каждой статьи.
- Alt индивидуальной OG-карточки гайда содержит заголовок статьи; общая карточка сохраняет название бренда.
- Разделитель хлебных крошек остаётся с последующим пунктом при переносе.
- Страница 404 использует единственный main внешнего layout; ссылка перехода к содержимому локализована на ru/kz/en/zh и ведёт к фокусируемому main.
- Название теста редиректа отражает сохранение значений query, а не побайтового представления.

## Границы

Данные участков, публичные бизнес-тексты, контакты и дизайн не меняются. OG-шрифты и версионирование изображения остаются для сессии 4 с утверждённой карточкой. Работа с внешними аккаунтами и публикациями ждёт входа/решений владельца.
