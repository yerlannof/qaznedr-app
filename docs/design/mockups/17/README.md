## Что проверено ведущим

375 и 1440 px: светлая/тёмная тема характеристик, отсутствие горизонтального переполнения,
возврат с сохранением полей, смена буровой на компрессор без утечки нерелевантных параметров,
локальный предпросмотр синтетического PNG, Google/email демо, описание/условия в предпросмотре,
демонстрационный статус модерации. Итог — `qa.json`, замечаний нет.

Проверка полноты предпросмотра сначала обнаружила отсутствие описания/условий;
после исправления тот же сценарий прошёл на обоих размерах.
Независимое ревью спецификации, плана, макета и исследования OpenMontage — Ready;

## Границы

- Это форма для согласования, а не работающий портал. Вкладка каталога содержит только вводный экран.
- Новые поля пока на русском; переключатель языка переводит оболочку. Проверка всех четырёх языков ещё впереди.
- Данные находятся в памяти вкладки; настоящих входа, писем, серверной загрузки/сохранения и публикации нет.
- Выбранные изображения видны через локальные object URL; закрытие вкладки очищает их. Проверена одна демо-картинка.
- Поиск, модерация и SEO карточек описаны в плане; этим HTML они не реализованы.
- Продакшен, миграции и feature flags не изменены.

Серверный словарь и связанные возможности выпущены отдельным закрытым этапом.
Реализация формы и её фактические границы отражаются в
`docs/visibility/2026-10-04-equipment-intake-release.md`; снимки в этой папке
относятся к исходному макету, а не к live OAuth или production модерации.
