## Что уже работает и чего нет

- В действующем layout стоят Vercel Analytics и Speed Insights.
- События: click_whatsapp, wechat_copy, inquiry_submit. Последнее вызывается после успешного API; заявки сохраняются в Supabase, при настроенном Telegram выполняется попытка уведомления (доставка не гарантирована).
- `wechat_copy` вызывается до успешного копирования: исправить семантику события.
- UTM заявки считываются с текущего URL при отправке. После внутреннего перехода могут теряться; не сохранены первый вход и исходная посадочная страница.
- Действующих GA4, Яндекс.Метрики, Google Ads/GTM/Meta/TikTok pixel в текущем публичном коде не найдено. Legacy analytics utility не подключён к действующим страницам.
- В доступном кабинете Яндекс.Метрики найден только чужой по назначению счётчик Game Over; не использовать его для QAZNEDR. GA4-кабинет не проверен успешно.
- Публичного управления рекламным согласием нет. Не включать все рекламные пиксели автоматически.
- Старый dashboard/analytics относится к legacy marketplace, не является отчётом о текущей воронке холдинга.

## Очередь работ

1. **Измерение заявок:** сохранять ограниченные UTM/source/landing с внутренними переходами; разделить клик, успешное копирование и отправленную заявку; не отправлять телефоны, email, текст заявки в сторонние события. Контрольный сценарий: tagged landing → каталог → карточка → форма сохраняет исходную атрибуцию. Определить срок хранения/согласие до реализации.
2. **GA4 и Метрика:** проверить/создать именно ресурсы QAZNEDR, согласовать публичный механизм согласия и назначение, подключить минимальный набор целей. Рекламные аудитории начнут накапливаться после корректного подключения; старая статистика Vercel не готовый список для догоняющей рекламы.
3. **Контент по спросу:** пилот «карта золота ВКО» после получения материала и разрешённого объёма; см. спецификацию. Затем карты/регионы/металлы, где есть подтверждённые данные и коммерческая связь.
4. **Скорость:** отдельно измерить карточки на мобильных устройствах и из нужных стран; установить причину до оптимизации. Данные недели смешивают версии сайта.
5. **Еженедельный отчёт:** новые небрендовые показы и клики по страницам; посещения; реальные заявки и их качество; успешные контакты; источник. Контрольные точки через 2/4/8 недель после публикации — не обещание сроков результата.
