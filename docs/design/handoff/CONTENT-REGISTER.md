# Handoff: content register

Everything below is required input or editorial approval before corresponding content is published. Mark unprovided values as unavailable in internal data; do not fill them with plausible invented values. Preview placeholders are not content.

## Company owner / authorized representative

| Field                                                              | Required or optional                             | Use / fallback                                                                        |
| ------------------------------------------------------------------ | ------------------------------------------------ | ------------------------------------------------------------------------------------- |
| Exact legal entity name, BIN, registered address                   | Required for company verification page           | Withhold verification claims and registry links until confirmed.                      |
| Official registry URLs and checked-on date                         | Required when verification links are shown       | Hide links pending confirmation.                                                      |
| Real WhatsApp number; real WeChat ID and scannable QR              | Required for each channel displayed              | Hide a channel if missing; never expose a sample number/QR.                           |
| Business email                                                     | Optional channel                                 | Hide if unprovided.                                                                   |
| Reply hours, timezone, supported reply languages                   | Required before publishing availability promises | Say response details are unconfirmed internally; do not infer from interface locales. |
| Form recipient, privacy/retention wording, delivery/error behavior | Required before enabling submission              | Keep preview non-sending; do not collect user data before an approved working flow.   |

## Geology / portfolio team

| Field                                                                                                 | Required or optional             | Use / fallback                                                                                                |
| ----------------------------------------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Real candidate project records: stable internal ID/slug, public code, metal, region, project type     | Required per published card      | Exclude incomplete records; never publish DEMO identifiers.                                                   |
| Open fields: area, licence/permit type, terms, associated metals                                      | Required only when asserted      | Omit unknown values; no fabricated ranges, coordinates, areas or prices.                                      |
| Grade/assay value, unit, sample basis (average/range/local high), report/source and page, review date | Required if grade is displayed   | “Data pending” or omit; never substitute a local high for an average or imply reserves.                       |
| Current availability/status and supporting official source, checked date, limitations                 | Required per public teaser       | Use “status pending verification”; hide availability CTA until checked.                                       |
| NDA package contents and actual release process                                                       | Required before promising access | Describe only materials available and process approved by the team; signing must not imply automatic release. |
| Team member name, role, approved bio, real photo/consent                                              | Optional per profile             | Omit profile until supplied; no invented credentials, tenure or deals.                                        |
| Insight/article technical facts and geological reviewer                                               | Required per technical claim     | Hold publication pending qualified review.                                                                    |
