# Закрытая очистка фотографий техники — 30.09.2026

Начало: HEAD/origin/master/Production `d10a186`, deployment 6747137495 — success.
Спецификация: `docs/superpowers/specs/2026-09-30-equipment-image-cleanup-design.md`.
Этап касается существующей очереди удалённых attachments. Публичные страницы,
новые тексты, флаги каталога, регистрация и production-БД не меняются.

## Контракт

Worker удаляет только точный UUID-путь из закрытой очереди и только в приватном
bucket `equipment-images`. После успешного Storage.remove задача подтверждается;
неизвестный результат или отказ не считается завершением. Завершённая запись
остаётся tombstone и запрещает повторную привязку ID/пути.

SQL claim/ack/fail доступны только service_role. Lease и случайный token ограждают
старое подтверждение от новой попытки. Пять попыток — верхний предел перед ручным
разбором. Worker получает свежую задачу по одной, не расходуя попытки остальных
при задержке текущей. CLI выполняет один ограниченный проход только при явном
opt-in и явно заданной целевой среде; каждый сетевой запрос ограничен 20 секундами
при lease 120 секунд. Он не подключён к HTTP, cron или deploy.

## Ревью и исправления

Независимый сильный агент воспроизвёл три P2 в исходном варианте: общий image ID
на разных родителях обходил сериализацию; REPEATABLE READ сохранял старый snapshot
после ожидания; предварительный claim всей пачки расходовал попытки нетронутых
задач при задержке первой. Все три исправлены через red/green: общий advisory lock
по image ID, отказ guards при изоляции кроме READ COMMITTED, singleton claim.
Повторное сильное ревью — Ready; обе исходные SQL-гонки reviewer перепроверил
в отдельной клонированной и затем удалённой fixture. Новых P1/P2 не обнаружено.

Личная проверка ведущего также обнаружила ошибку типов CLI: реальный Supabase RPC
возвращает PromiseLike, а не Promise. Обычный project tsconfig исключает scripts;
поэтому CLI проверен отдельным временным конфигом с реальным SupabaseClient.
Контракт исправлен на PromiseLike без приведения клиента к небезопасному типу.
