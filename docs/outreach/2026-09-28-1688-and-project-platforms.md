## 1688

Официальные [Terms of Use](https://terms.alicdn.com/legal-agreement/terms/common_platform_service/20240913201059451/20240913201059451.html) предусматривают зарубежных пользователей, включая регистрацию зарубежным телефоном/email/сторонним аккаунтом в доступных сценариях. Поддержка конкретного казахстанского номера и оплаты требует живой проверки. Начать с собственного аккаунта владельца; Alipay у него уже есть. Ничего не покупать и не менять регион/личность ради входа.

[Privacy policy, payment](https://terms.alicdn.com/legal-agreement/terms/privacy_policy_full/20230919144510933/20230919144510933.html) описывает Alipay/MYBank и другие способы; это не гарантия оплаты казахстанской картой/балансом для любого товара. До закупки сравнить товар, MOQ, продавца, доставку/посредника, итоговую стоимость. Товар/количество/бюджет владелец пока не указал.

## API

[1688 Open Platform](https://aop.alibaba.com/) / open.1688.com: регистрация разработчика, одобрение приложения, app key/secret и права конкретных методов; некоторые сервисы платные. [Partner agreement](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_b2b/suit_bu1_b2b202002111645_28701.html). Доступный этому владельцу официальный универсальный API поиска всех товаров по ключевому слову НЕ подтверждён. Не выдавать Taobao API за 1688 API. Ключей нет, интеграция не создана. До подтверждения — поиск/сравнение через официальный сайт/приложение. Секреты вне Git.

## Лицензированные проекты

- [AIFC Junior Mining Platform](https://aifc.kz/project-pipeline-development/): принимает заявки держателей проектов с действующими лицензиями, отбирает проекты и представляет инвесторам. Это более прямое соответствие задаче, чем товарное объявление Alibaba. Приём конкретного проекта/условия не подтверждены, ничего не отправлено.
- [Alibaba seller rules](https://seller.alibaba.com/pages/seller_onboarding_rules.html): нельзя искажать товар/категорию. Прямого проверенного разрешения или запрета на объявления о доле/лицензии месторождения не найдено. Сначала письменное уточнение правил; не маскировать проект под руду/оборудование.
- [Minerals e-Qazyna](https://minerals.e-qazyna.kz/en/start): государственная платформа лицензий/реестра/аукционов/процедур перехода прав, не частная доска инвестпроектов. Полезна для проверки реквизитов, а не замена маркетинговой площадке.

Следующее: проверить вход 1688 в существующем Alipay/собственном аккаунте без новой покупки номера; уточнить категории закупок. Для публикаций получить конкретный список лицензий, держателей и утверждённых раскрываемых данных через геобазу. Регистрация, API-заявка, объявления и внешние сообщения по этим новым направлениям ещё не выполнены.
