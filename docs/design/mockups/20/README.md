# 20 — кабинет автора «Мои объявления» (на утверждение)

Открыть: [review/20-owner-cabinet.html](../../review/20-owner-cabinet.html). Скриншоты: `desktop-ru.png` (1440), `mobile-ru.png`, `mobile-dark-ru.png` (375). Без горизонтального переполнения на 1440 и 375.

Показывает этап 4 плана маркетплейса: один список объявлений автора с фильтром по статусу (черновик, на проверке, опубликовано, отклонено, архив); причину отказа и «Исправить и отправить снова»; отметки доверия с датой у опубликованных; изменение опубликованного снова через модерацию (на время проверки объявление не видно в каталоге — так работает текущая логика); снятие с публикации; продолжение черновика. Справа контакт по умолчанию, помощь с размещением через WhatsApp и выход. Удаления нет — архив. Тексты RU; KZ/EN/ZH после утверждения. Стиль A3/D2, кнопки 44–48 px.
