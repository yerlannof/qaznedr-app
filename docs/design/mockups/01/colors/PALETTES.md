# Палитры A3 «Контур» — варианты для выбора

Статус: все четыре палитры предложены на рассмотрение; ни одна не утверждена. Форма логотипа A3 «Контур» и его lettering одинаковы во всех вариантах, сравнивается только цвет. Каждый вариант следует показать в светлой и тёмной темах и на концепте мини-hero сайта. Это сравнение цвета, не утверждение структуры сайта.

## Кнопка основного действия

- Светлая тема: фон `dark-bg`, текст `light-bg`.
- Тёмная тема: фон `accent-dark`, текст `dark-bg`.

## Показ вариантов

Для каждого P1–P4 показать одни и те же элементы: направление A3 и lockup, мини-hero сайта в светлой теме, мини-hero в тёмной теме, кнопки основного действия. ImageGen лишь приблизительно передаёт цвета; точные значения задаёт эта таблица.
