## Границы

- Не дублировать гайды по картам, лицензиям и классификации запасов: новая задача — собрать проверяемый комплект материалов до решения о следующем этапе работ.
- Не выдавать чек-лист за полную экспертизу, отчет KAZRC/JORC, оценку стоимости, правовое заключение или доказательство запасов. Нет утверждений об обязательности JORC для любого проекта Казахстана.
- Только имеющиеся услуги, без гарантии результата, выдуманных кейсов, имени эксперта, цифр по участкам или заявления о собственности.
- Пример должен быть явно учебным; не использовать закрытую геобазу. Сохранить встречу/NDA для раскрытия материалов команды.
- Существующий дизайн статьи. Нового UI в этом этапе нет. Публикация, registry/sitemap и IndexNow — после конкретного утверждения текста.
- Не возвращать баннер согласия автоматически: макет15 остается отдельным решением.

## Критерии готовности

Проверенные первоисточники, короткий ответ, полезная таблица исходных данных, ясный следующий шаг для читателя, согласованные четыре языка, отсутствие битых локальных ссылок, независимое редакционное ревью. Статус «черновик» явно указан. Локальные материалы и фактические проверки сохранены для продолжения.
