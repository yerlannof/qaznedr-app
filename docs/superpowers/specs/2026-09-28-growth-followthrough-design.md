# Доводка измерений и следующая редакционная очередь

Продолжение поручения владельца «делай дальше … по полной программе», 28.09.2026. Предыдущий выпуск: HEAD/origin/master/успешный Production `29accd8`.

## Результат сессии

1. Устранить известный сбой CI форматирования. Старые HTML/CJS-макеты форматируются штатным Prettier; точные файлы подтверждения Google/Яндекса исключаются из форматирования и остаются побайтно неизменными. Проверка остального проекта сохраняется.
2. Исправить непосредственный referrer при SPA-переходах: внешний домен только для первого просмотра, предыдущая публичная страница для следующих, та же ссылка для событий текущего просмотра. Сброс при отзыве согласия. Query/hash, private paths, пользовательские контакты не передавать. Произвольные UTM и click-ID по-прежнему не передаются в GA/Метрику: это утверждённая граница, а не дефект. Атрибуция заявок остаётся отдельной.
3. Проверить фактическое состояние доступных поисковых кабинетов/Метрики; фиксировать наблюдения отдельно от гипотез.
4. Подготовить один содержательный гайд о выборе геологической карты для согласования. Использовать существующую композицию гайдов, без нового дизайна, выдуманных карт и обещаний их наличия. Публикация текста — после решения владельца; локальный черновик публикацией не считается.

## Приёмка

Полный Prettier check проходит, файлы верификации не изменились. Referrer покрыт сначала падающим, затем проходящим тестом; согласие и приватность не ослаблены. Полный Jest сравнивается с известной baseline, ESLint/build/typecheck; браузерная проверка переходов. Независимое ревью и подтверждённый Production своего SHA. Реклама, новые регистрации/рассылки и данные участков не входят в изменение.
