## Официальные способы подачи: проверены ограничения

**Baidu.** Официальный обычный приём описывает API, sitemap и ручную подачу.
Для API требуется token проверенного сайта; успех запроса означает приём URL,
не индексацию. Повторная подача старых URL расходует квоту и может снизить её.
Руководство указывает обычный списокURL XML/TXT, не sitemap-index; наш текущий
sitemap —обычный urlset и подходит по форме. Квоты конкретного сайта пока
неизвестны, поскольку кабинет недоступен.

В реальном Chrome открыта публичная форма
https://ziyuan.baidu.com/linksubmit/url. Введён только публичный
https://qaznedr.kz/zh и нажато提交: сайт перенаправил на
https://ziyuan.baidu.com/login/index?u=/linksubmit/url. **Успешной подачи нет**.
Никаких CAPTCHA, соглашений или новых SMS не выполняли. Это исключает обещание
«отправили без аккаунта» на основании одной видимой формы.

**Sogou.** Sitemap доступен по приглашению для проверенного сайта. Официальная
справка разрешает запросить доступ по zzpt@tencent.com при оригинальном/ценном
контенте или проблеме обхода, но сначала надо проверить сайт и фактическое
наличие приглашения. Полная проверка субъекта дополнительно перечисляет ICP,
китайский регистрационный код и ID оператора; применимость к зарубежному ТОО
не подтверждена. Не считать эти поля обязательными для самого органического
обхода. HTML/file verification и последующая полная проверка субъекта различны.

**360.** Официальная справка ссылается на форму подачи; её живое открытие через
Firecrawl перенаправило на360login (i.360.cn). Кабинет zhanzhang.so.com содержит
sitemap/анализ/verification. Свободная подача без входа в текущей проверке не
подтверждена. Их справка прямо не обещает включение всех страниц.

**Публичная выдача.** Live-fetch запроса site:qaznedr.kz в Baidu вернул
«未找到相关结果» —в этой выборке результатов нет. Это не полный отчёт индекса
и не диагноз причины; отсутствие всех страниц в индексе не устанавливается.
Sogou ответил anti-spider CAPTCHA, результаты не прочитаны и индекс не оценён.
Ограничения не обходились. Firecrawl не является проверкой из нескольких
материковых сетей.

## Следующие шаги по порядку

1. **Доступ Baidu:** проверить ответ/приём существующего обращения о статусе
   номера; завершить допустимый официальный вход. После входа подтвердить
   именноhttps://qaznedr.kz через файл/тег, получить разрешённую квоту/token,
   подать sitemap и новые/изменённые ZH URL, записать реальный результат приёма.
   Затем измерять индекс/показы/клики. Техническая поддержка meta уже есть в
   locale layout; секреты в env, не в Git.33публичныхURL сохранены локально
   `/tmp/qaznedr-china-public-urls.json`; это подготовка, не внешняя подача.
2. **Sogou и360 отдельно:** проверить реальный допустимый вход/права кабинета.
   Для Sogou выяснить зарубежный статус субъекта и приглашение sitemap;
   для360 —верификацию домена и доступный способ подачи. Не покупать чужие
   кабинеты и не принимать новые соглашения автоматически.
3. **Доступность из Китая:** измерить страницу/критические assets из нескольких
   материковых провайдеров и городов. Только по доказанной проблеме выбирать
   ускорение/зеркало; не менять домен/хостинг/ICP на основании предположения.
4. **Оригинальные китайские материалы и входящие ссылки:** использовать уже
   утверждённые12гайдов,6хабов по металлам, услуги и5тизеров; публикация
   материалов на доступных китайских профильных площадках/WeChat/Zhihu/Douyin
   с соблюдением их правил может дать аудиторию и обнаружение ссылок.
   Новые публичные тексты/профили —по действующему процессу утверждения.
   Аккаунт без публикаций и купленные ссылки результатом не являются.
5. **Измерение:** различать доступность, приёмURL, индекс, запросы/показы,
   китайские реферальные визиты, конкретные обращения и реальные LLM-цитаты.
   Не обещать топы/присутствие во всех моделях. Google/Bing-китайская версия
   продолжает работать независимо от регистрации в Baidu/Douyin.
