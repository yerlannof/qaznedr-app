# Сессия 7б — надёжность поиска и фактическая видимость

## Задача и границы

По поручению Ерлана от 27.09.2026 продолжить пункты 6/7, усилить SEO,
доступность для поисковых ИИ и китайской/международной аудитории. Владелец
уточнил: аккаунта Douyin нет; затем разрешил работать самостоятельно,
не ожидая ответов. Это не утверждение новых публикаций, реквизитов или дизайна.

Сохраняем A3/D2, сцену 10, подачу участков и все утверждённые тексты.
Не меняем строки leads/lead_private, секреты, DNS или права доступа.

Старт: HEAD = origin/master = Production `9394dfb`, deployment 6684796041 success.

## Обнаружено

- Production `/` уже имеет серверный 307 из vercel.json. Клиентская заглушка
  в src/app/page.tsx — локальная несогласованность, а не отсутствие redirect на проде.
- `/sitemap.xml` содержит 200 URL (RU 51, KZ 47, EN 51, ZH 51).
- Генератор sitemap проглатывает ошибки API; сбой второй страницы обрывает
  список, общий catch удаляет все тизеры. Такой результат выглядит успешным.
- Фиксированная дата 26.09 присваивается и участкам без известной даты изменения.
- GSC и Bing приняли предыдущий sitemap (176 URL, 26.09); статистика обрабатывается.
- GSC для `/zh` хранит обход 09.06.2026 с прежним redirect на www. Это историческое
  состояние индекса, не текущий HTTP-ответ (сейчас 200).

## Решение

1. Единый серверный 308 `/` → `/ru` в middleware, с сохранением query,
   одинаково локально и в Vercel. Убрать перекрывающий временный Vercel redirect;
   клиентскую загрузочную страницу заменить серверным fallback redirect.
2. Полный снимок кодов sitemap: проверять HTTP, success, пагинацию, число строк,
   стабильность total, уникальность/валидность кодов; ограничить число страниц.
   Кэшировать только успешно проверенный снимок через Next cache; не кэшировать
   отдельные HTTP-страницы. Ошибка должна выбрасываться, а не возвращать урезанный XML.
   ISR сохраняет предыдущую успешную версию при ошибке регенерации; без успешного
   снимка build/запрос может завершиться ошибкой — намеренно, вместо тихой потери URL.
3. Не указывать lastmod, когда нет достоверной даты изменения страницы.
   Даты гайдов из реестра сохранить; дату проверки свободности не выдавать за lastmod.
4. Проверить все URL production sitemap без JS, канонические/языковые ссылки,
   метаданные, H1 и JSON-LD. Проверить кабинеты GSC/Bing; запросить переобход
   существующих важных EN/ZH URL в пределах доступных инструментов.
5. Сохранить проверяемый протокол SEO/индексации и приоритеты Китая без Douyin.
   Отделять HTTP-доступность, принятие sitemap, индексацию, цитаты ИИ и заявки.
6. Обход всех 200 URL выявил отсутствие JSON-LD у каталога `/leads`.
   Добавить невидимую CollectionPage + ItemList из реально показанных карточек,
   с существующими локализованными текстами и без новых бизнес-утверждений.
   Пустая выдача не содержит выдуманных элементов. Отсутствие schema у условий
   само по себе не препятствует индексации, юридический контент не менять.
7. Обнаружен неиспользуемый `scripts/ping-search-engines.sh`: закрытый Google
   sitemap ping и ложный безусловный Done. Вывести скрипт из эксплуатации
   с явным объяснением и ненулевым кодом выхода; новые сетевые отправки не добавлять.
   Проверить через stub curl, что он ничего не отправляет и не заявляет успех.

## Критерии готовности

TDD red→green для redirect и отказов sitemap; полный Jest без новых failures,
ESLint/build; HTTP и браузерная проверка. Независимый review, push master,
успешный Production и повторная проверка. Реальные блокеры записаны в roadmap.
Ни один технический результат не называется гарантией позиции, трафика или цитирования.

## Официальные основания

- Google: https://developers.google.com/search/docs/appearance/ai-features — обычные
  SEO-требования, индексируемый текст, внутренние ссылки, согласованная разметка.
- Next ISR: https://nextjs.org/docs/app/guides/incremental-static-regeneration —
  ошибка регенерации сохраняет последнюю успешно созданную версию.
- Baidu: https://ziyuan.baidu.com/college/courseinfo?id=267&page=2 — подтверждение
  сайта и отправка sitemap; отправка не гарантирует индексацию и позиции.
- Bing: https://www.bing.com/webmasters/help/ai-performance-9f8e7d6c — отчёт о
  цитатах является измерением цитирования, а не рейтингом или авторитетностью.
