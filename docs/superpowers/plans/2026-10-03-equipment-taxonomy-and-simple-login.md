## Следующие этапы

1. **Закрытая taxonomy v2.** Кандидатные пути: новый `src/lib/equipment-listings/taxonomy.ts`, существующие `domain.ts`, `repository.ts`, тесты в `src/__tests__/lib/equipment-listings/`; при необходимости отдельная forward-only migration в `supabase/migrations/`. Не редактировать lead/deposit схемы. Перед выдачей агенту зафиксировать точный список файлов. TDD до изменения: матрица offer/category/method, связанные capabilities, единицы, неизвестные значения, старые записи, запрет лишних полей. Без production SQL.
2. **Закрытый поиск/предпросмотр.** Новый модуль query/filters в equipment-listings и зеркальные тесты. Одни коды/единицы для подачи и поиска, EXISTS по одной строке возможностей, public allowlist, только ACTIVE; ограниченные параметры и пагинация. Не открывать прежние routes и не добавлять каталог в sitemap раньше ограниченного запуска.
3. **Простой вход.** Отдельная узкая спецификация: adapter/token persistence, доступный отправитель без записи секретов, rate limits и доставка, явное связывание identity; экраны Google/email с возвратом в черновик, профиль/контакт отдельно. Google callback уже есть; не заменять admin route и не включать flags без сквозного QA. Если sender/credentials отсутствуют — закончить локальные contract tests и продвигать независимую форму, не обещать отправленный email.
4. **Утверждённая форма.** Четыре шага, autosave, фото с телефона, ошибки рядом с полем, «не знаю» для необязательного параметра; предпросмотр/очередь/отказ/правка/архив. Краткая помощь по размещению с существующим контактом команды. Все четыре языка и обе темы.
5. **Предпусковая проверка.** Полный закрытый HTTP+DB lifecycle; квоты, rate limits и retention; одобренный пилот, ответственный модератор, публичные условия/приватность. Затем отдельный план безопасной production migration и ограниченного включения. Не открывать marketplace простым снятием 308.
6. **Публичный SEO выпуск.** Стабильные URL карточек/категорий, canonical/hreflang/metadata, корректные sitemap/schema, политика обхода фильтров, архив/удаление, внутренние ссылки. IndexNow только для реальных изменений. Метрики started/submitted/approved/contact, формы и клики раздельно.
