# Задание 04. Портфель и тизер участка

**Зависит от:** 01 и 02 утверждены.

## Цель

Это главные продающие страницы: 20–40 сильных участков. Карточка должна вызывать интерес и доверие, а тизер — желание написать в WeChat или WhatsApp.

## Что сделать

1. **Каталог портфеля:**
   - фильтры по металлу, региону и типу; пустое состояние; мобильные фильтры в выезжающей панели;
   - карточка участка: код (например `AU-508A4C`, `CU-1F2E3D`), металл, регион, тип месторождения, содержание диапазоном с меткой «среднее / спайк / шлих», «свободен по нашей проверке на ДАТУ», бейдж «закрытый тизер», попутные металлы.
2. **Тизер участка:**
   - открытые параметры;
   - блок «после NDA» с размытыми строками без реальных данных;
   - **блок «Обсудить участок» (WeChat первым на 中文, WhatsApp на остальных, ниже форма)**;
   - форматы сделки;
   - «как проверить сведения самостоятельно»;
   - юридический дисклеймер: переход прав требует разрешения МПС РК, статус проверен по публичной карте на дату.
3. **Китайская версия тизера:** поля в привычном формате 矿种 / 位置 / 面积 / 许可类型 / 价格面议.
4. **Состояния:** участок продан, участок в переговорах, нет данных о содержании.

## Правила текста

- Спайк не равен среднему, показываем оба с метками.
- P1–P3 — это прогноз, а не запасы.
- Слабые объекты не хвалим.
- Не пишем, что участок принадлежит холдингу.
