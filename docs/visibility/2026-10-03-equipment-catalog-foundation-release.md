# Буровые объявления — закрытая серверная основа, 03.10.2026

По поручению владельца начать портал буровых объявлений. Новая форма показана в design17, решение по внедрению ещё ожидается. Этот выпуск добавляет серверную схему и поиск; публичный портал, OAuth/email и приём реальных объявлений пока не запущены.

## Что сделано

- Семь методов бурения, отдельные назначения/траектория/площадка; связанные строки метод + диаметр скважины + рабочая глубина и типоразмер CORE.
- Условные параметры буровых/экскаваторов/компрессоров/транспорта; год и состояние при продаже, оператор/доставка, цена по запросу, длительность смены. Неизвестные характеристики допустимы; v1 совместим, v2 включается явно.
- Валидируемые фильтры, нормализация регистра/NFKC/ё и точных синонимов методов. Свободный текст не превращается в SQL. Поиск по точному диаметру и минимальной глубине в одной строке. Установку CORE1200/96 + RC200/200 нельзя выдать за CORE1200/200.
- Service-only RPC с ACTIVE, ограниченной пагинацией, стабильным порядком; сравнение цены в одной валюте/единице/длительности смены. Неизвестные характеристики не равны нулю.
- HTTP API `/api/equipment-catalog`: публичная allowlist-проекция без owner ID, заметок модерации и приватных контактов. Нужны одновременно два отдельных флага; оба оставлены выключенными. Ответы no-store/noindex.
