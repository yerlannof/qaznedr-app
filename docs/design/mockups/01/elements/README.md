Оба рисунка без надписей, логотипов и числовых данных, поэтому переиспользуются в RU / EN / 中文. Это художественные схемы, не фотографии реальных материалов компании или образцов конкретных участков. По ним нельзя определять состав и содержание металлов.

Гравюрный характер и фирменные цвета сохранены. Генерация дала небольшую неоднородность фона: для бесшовной вставки в страницу потребуется отдельная подготовка краёв/прозрачности; до неё применять как цельные изображения. Золотистые вкрапления остаются иллюстративным мотивом. Эти файлы не заменяют единый согласованный объект для scroll-анимации.
