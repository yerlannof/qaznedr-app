## Правила работы

- **Одно рабочее место:** `~/Documents/qaznedr-app` на Mac.
- **В начале каждой сессии** сверять локальную папку, `origin/master` и коммит продакшена: GitHub Production Deployments, SHA и статус success (см. AGENTS.md).
- **Деплой = push в master.** Vercel сам собирает прод из GitHub (интеграция включена 2026-09-26). Перед push — build и тесты. `vercel --prod` не запускать, иначе будет двойная сборка. Ветки получают превью под SSO Vercel.
- **Astra (Codex)** ведёт дизайн и код; верстается только то, что записано в `APPROVED.md`. Дизайн-субагенты пишут только в `docs/design/`.
- **Данные участков** публикует только геобаза («50 точек») через свой гейт и «да» Ерлана. Задачи геобазе ставит только Ерлан.
- **Красные линии текста:**
  - не писать и не намекать, что участок наш;
  - не писать, что продаём архивные отчёты;
  - «свободен» = «по нашей проверке на дату»;
  - спайк ≠ среднее, P1–P3 — прогноз, а не запасы;
  - без «гарантированной доходности»;
  - без упоминания OCR, ИИ и моделей — это труд наших геологов.
- **Файлы подтверждения поисковиков** в `public/` (`google…html`, `yandex_…html`, `BingSiteAuth.xml`) не удалять, иначе права в кабинетах слетят.
- **Пароли** на сайтах владелец вводит сам: Claude в Chrome их не вводит.
- **Старые тесты маркетплейса**, падающие ещё до нашей работы (5–6 наборов), не чиним. Новых падений быть не должно.
