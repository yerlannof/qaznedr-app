Чтение AX/снимков и некоторые AX-кнопки/клавиши работают. Выход Chrome из полного экрана и разворачивание окна не восстановили координатные нажатия. Через WeChat меню Window → WeChat (Chats) доступен чат; нажатие карточки открывает сообщение, снимок позволяет прочитать код. Пользователю задан единственный ручной шаг: нажать 获取验证码 в открытой форме; чтение и ввод следующего SMS агент делает сам. Регистрация ещё не подтверждена.

Продолжение самостоятельной попытки: ручной клик владельца затем отменён в сообщении — AX-нажатие всё-таки дало подтверждение 验证码已发送 с задержкой. Последующее подключение Chrome 1 исчезло; после явного Browser is not available инвентаризация нашла Chrome Gosu с новым ID 3, агент переподключился официальным API. Вкладка 2118640228 сохранена. После свежего запроса в 12:36 пришёл новый SMS; агент сам прочитал и ввёл его. Браузерный вызов во время ввода оборвался native pipe closed before response; ввод затем подтверждён AX нативного Chrome. После Enter и кнопки 登录 форма осталась открытой, нового профиля/успеха нет. Не считать вход завершённым. Часть вызовов занимает 10–22 секунды, подключение и нативные клики нестабильны; новые OTP в этот момент не запрашивать по кругу. Просьба о ручном клике из async-вопроса больше не актуальна.
