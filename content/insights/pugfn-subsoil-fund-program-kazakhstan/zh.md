PUGFN是国家底土资源管理计划，说明国家计划如何利用底土区域。对申请人来说，它是判断目标区域可能按照何种程序提供的文件之一。

计划中的记录或地图上的颜色，本身并不授予勘查或开采许可。还须核实当前状态、限制条件并取得相应权利。

本文依据截至2026年9月29日核查的规定编写。具体矿区状态可能变化，应在申请当日另行核查。

## 不要混淆三类资料

| 资料                                 | 有助于回答的问题                           |
| ------------------------------------ | ------------------------------------------ |
| 地质图及地质资料                     | 对该区域的地质和矿产了解多少？             |
| PUGFN及底土利用统一平台（EPN）的信息 | 该区域拟采用什么授予程序？目前有哪些资料？ |
| 许可证或合同                         | 底土利用人取得了什么具体权利？条件是什么？ |

例如，地图上显示金矿化点，并不表示矿区空闲、适用于任何申请，或存在经确认的储量。

## 计划包含哪些信息？

《底土与底土利用法典》（以下简称《底土法》）第70条规定，计划涉及国家地质研究区域、拍卖区域、拟提供给国家公司的区域、普通矿产开采区块，以及法典规定的其他用途。

对申请人更有用的问题是：**选定区域属于哪一类，应按什么程序取得权利？** 固体矿产勘查与个体小规模采矿不能直接套用同一程序。

## 第一步：确定地点和目的

准备州和区的名称、区块代码或目标区域边界。另行明确目的：勘查、开采、个体小规模采矿，还是初步地质评估。

旧报告中的矿点名称可能与现行行政区名称不同。准确核查需要坐标及原始资料信息，只有俗称不够。

## 第二步：查找最新官方资料

从[底土利用统一平台（EPN）](https://minerals.e-qazyna.kz/ru/minerals/gosuslugi)和主管机关的官方资料开始。核查申请当日有效的计划、修订及平台信息。

请记录：

- 核查日期和来源网址；
- 核查的区块代码或边界；
- 区域类别及相关文件；
- 发现的限制或重叠；
- 仍需进一步核查的问题。

旧地图截图只能证明过去做过核查，不能证明今天的状态。

## 第三步：核查限制和重叠

将目标区域与现有权利、授予程序及限制条件逐一比对。具体作业还须考虑《底土法》第25、26条以及对应底土利用方式的特别规定。

重点问四个问题：

1. 他人是否已享有该区域的有效权利？
2. 适用普通申请程序、拍卖还是特殊制度？
3. 是否存在土地、水体、保护区或地面设施方面的限制？
4. 计划作业需要哪些同意和文件？

某一地图图层没有显示限制，不等于完全没有限制。资料冲突时，应向主管机关核实状态，而不是选择对自己有利的版本。

## 第四步：决定下一步

| 核查结果                 | 下一步                                               |
| ------------------------ | ---------------------------------------------------- |
| 区域看似适合拟提交的申请 | 核查相关许可证的文件、现行程序及条件                 |
| 区域实行拍卖             | 核查具体拍卖的条件和文件                             |
| 他人享有有效权利         | 核查能否依法交易及权利人的权限；不要把区域称为“空闲” |
| 发现限制或资料冲突       | 在投入准备费用前澄清状态及作业可行性                 |
| 地质情况不清楚           | 先审阅原始资料并确定后续研究范围                     |

## 2026年PUGFN编制规则有哪些变化？

2026年5月15日第236号令批准了计划编制规则，包括收集资料、编制和协调计划、地质领域国家运营者的参与，以及通过EPN发布信息。规定至少每半年编制一次计划。

这并不意味着每块区域每半年都可取得，或其状态在两次编制之间不会变化。计划编制规则与经修订的现行计划是不同文件。

该命令的官方页面记载的发布日期是2026年5月20日。命令在首次正式公布之日起满十个日历日后生效；按该日期计算，为2026年5月31日。

## 常见问题

**区域列入PUGFN，就表示空闲吗？** 不能这样判断。须核查类别、现有权利、限制及适用的授予程序。

**看完地图就能开工吗？** 不能。查询资料不能代替取得权利和满足作业要求。

**能购买计划中的矿区吗？** 先弄清交易对象：申请新权利、转让现有权利，还是收购公司权益。这些交易适用不同规则。网站上的广告不会使底土变成普通商品。

**可以通过QAZNEDR提交申请吗？** 政府申请须按法定程序提交。团队可以讨论您的需求和所需准备；通过网站联系团队不等于提交政府申请。
