# Сессия 4 — айдентика, главная и общая навигация

Дата: 2026-09-26. Макеты 03–06 утверждены владельцем в этой сессии, см. APPROVED.md. Источник композиции: `docs/design/mockups/03/spec.md`, браузерный `site-preview.html`, D2 в `brand/brand.md`.

## Что реализуем

1. Семантические токены D2 (`brand-bg`, `brand-surface`, `brand-ink`, `brand-muted`, `brand-line`, `brand-accent`, `brand-slate`, `brand-chalk`) с обеими темами, доступным фокусом и CJK-стеком. Контент 1200 px, поля 20/32 px, крупные изображения, прямые линии, минимальные скругления. Прежние токены оставляем до миграции остальных страниц.
2. Общая навигация и футер D2. На десктопе язык доступен в шапке; на телефоне язык внутри меню. Меню сохраняет Escape, trap-focus, возврат фокуса. URL языка сохраняет текущий путь. Рабочие admin/logout сохраняются.
3. Вместо нижней панели — одна мобильная кнопка связи; на тизере якорь к его каналам сохраняет код и не теряет контекст. На contact и admin не дублировать действие. Минимум 44/48 px, отступ safe-area.
4. Главная: короткое представление + каналы → реальные опорные факты → статичная геологическая сцена → реальные участки → форматы/процесс → экспертиза → доверие → гайды → контакт. Все цифры только из успешного полного чтения; 7 152 подтверждено владельцем. При сбое не показывать выдуманные 31/9. Иллюстрации декоративные, без заявления о реальном образце участка. Командные фото и БИН без подтверждения не показывать.
5. Существующие согласованные тексты использовать из translations.ts: portal, leadsHero, dealSteps, insights, seo, contact. Главную отдавать сервером, чтобы ссылки и факты не зависели от клиентского fetch. Код приложения не импортирует docs/design.
6. OG-адреса версионировать. Локальные OG-шрифты с лицензией; исключить fetch Google Fonts при генерации OG, сохранить кириллицу/казахский/китайский.

## Отдельные решения

Владелец утвердил точный мастер A3 и пару Source Serif 4 / IBM Plex Sans из показа 07, а также светлую тему по умолчанию. Переносим файлы в public/brand; ручной выбор темы сохраняется, обе темы поддерживаются. Движение 08 не внедряем: в макете 03 разрешена статичная сцена.

## Проверка

TDD для мобильного контакта с кодом, переключения языка и меню, SSR главной и правильных ссылок kz→ru, отказа от фиктивных статистических чисел, версионирования OG. Визуальные стилевые правки проверять браузером, без тестов строк классов. Полный Jest (база 3в), ESLint, build, браузер 375/1440 × ru/kz/en/zh × обе темы, keyboard/reduced-motion. Lighthouse до/после; исследовать ухудшение. Независимое ревью, явный commit, push master, проверка Production.

## Уточнения реализации

Успешный полный снимок главной хранится 60 с в ограниченном однозаписном серверном кэше; сбой не кэшируется. Неполная выборка или превышение лимита страниц не превращаются в статистику. Числа форматируются одинаково в Node и браузерах независимо от установленного ICU. OG использует локальные IBM Plex Sans и подмножества Noto Sans SC; Next outputFileTracingIncludes явно включает TTF. Метаданные обычных запросов с User-Agent блокируются до включения в initial head (`htmlLimitedBots: /.*/`), чтобы description стабильно читался Lighthouse и потребителями HTML.
