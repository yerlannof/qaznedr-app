# Показ 15 — компактное согласие

Открыть локально: `../../review/15-compact-consent.html`.

Два адаптивных образца показывают 1440 px в светлой теме и 375 px в тёмной. Блок закреплён у нижнего края, не затемняет и не блокирует страницу. «Принять всё» и «Отклонить» доступны одним нажатием; «Настройки» открывают сведения о категориях. Кнопки в демонстрации только меняют вид макета: данные не сохраняются, счётчики не загружаются.

Это предложение для утверждения владельцем. Текущее решение `APPROVED.md` отключает автоматический баннер. При утверждении нового варианта потребуется заменить это решение и согласовать эквиваленты текста на KZ/EN/ZH. «Принять всё» относится только к раскрытым здесь Google Analytics и Яндекс Метрике; рекламные инструменты остаются выключенными и требуют нового раскрытия и согласования.
