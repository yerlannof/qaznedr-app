# 13 — техника и услуги: прототип для просмотра

Открыть: [review/13-marketplace-simple.html](../../review/13-marketplace-simple.html). Это отдельный локальный HTML-файл, не публичная страница и не утверждённый дизайн.

Проверяем два пути: фильтры каталога с отдельными типами «техника» и «услуга»; четыре шага подачи (тип → предложение → контакт → предпросмотр). Для буровой появляются метод, диаметр и глубина; для экскаватора — ковш и масса. Поля сохраняются при возврате, характеристики черновика — только в `sessionStorage` вкладки. Имя, компания, телефон и выбор публикации контакта в хранилище не записываются. Все предложения вымышлены и помечены DEMO.

Результат «ожидает модерации» является только экраном примера. Здесь нет отправки, загрузки фото, входа, подтверждения телефона, контакта с редакцией или реальной публикации. Помощь с размещением показывает необходимые сведения; настоящий канал редакции нужно согласовать до запуска. Цены, условия подачи и рабочий процесс модерации также ещё не утверждены. Фотографии с телефона намеренно не имитируются фиктивной загрузкой.

Проверка в локальном Chrome через Playwright: фильтрация услуг; прохождение формы; условные поля буровой; предпросмотр и демо-результат; смена языка и темы; 375 и 1440 px × RU/KZ/EN/ZH × светлая/тёмная без горизонтального переполнения; после перезагрузки сохраняются характеристики без персональных полей. Для обсуждения с целевой аудиторией 50–60 лет требуется отдельный очный/удалённый тест с 3–5 людьми.

Уточнение после просмотра: продажа техники использует цену за единицу техники; на шаге проверки видны условия, применимые технические параметры, компания, телефон и явный выбор видимости контакта. При смене категории прежние технические параметры удаляются. Отрицательные значения цены и технических чисел не пропускают дальше; проверено в Chrome на примерах экскаватора и буровой.
