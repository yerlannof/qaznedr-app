## Что сайт СЕЛЕКТИТ, но экспорт НЕ заполняет → пустые поля в UI

| Поле                       | Где в UI                               | Сейчас                                                       |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------ |
| `teaser_summary`           | подзаголовок тизера                    | всегда null → пусто                                          |
| `last_verified`            | «проверено [дата]»                     | null → fallback/пусто                                        |

**Это и есть главное расхождение:** сайт построен под более богатые данные, чем даёт текущий экспорт. Решение: либо мапить эти поля в экспорте (если они есть в реестре), либо убрать «мёртвый» UI.

## Прочие наблюдения

1. **mineral = "Au" хардкодом** — все находки золото. Фильтр на сайте предлагает Нефть/Газ/Медь/Уголь/Уран/Железо, но непустой только Au. → упростить фильтр находок (только золото) или оставить как есть.
2. **exclusivity = "MASS" хардкодом** — все находки одного тира, эксклюзив-лейблы не различают.
3. **status = "DRAFT"** на экспорте → публикация (DRAFT→PUBLISHED) ручная (есть в /admin/leads). 37 строк в lead_private; ~31 published.
4. **price_display всё ещё пишется** ("от 1 000 000 ₸"), но сайт его БОЛЬШЕ НЕ селектит (убрали из TEASER_COLUMNS) → цена не светится. Данные безвредны.
5. **lead_private.lead_id** — экспорт ставит при пуше (export_leads_to_portal.py:113 через idmap). Связь leads↔lead_private корректна, разблокировка работает. Бага НЕТ.
