# Переход гайд → услуги → обращение — 06.10.2026

## Что исправлено

Ранее прямой контакт из гайда сохранял его тему, но переход через страницу услуг терял источник. Теперь ссылки в тексте, меню и футере гайда передают зарегистрированный guide в каталог услуг и на страницы лицензирования/геологических работ. Их кнопки связи, возврат в каталог и переключение RU/KZ/EN/ZH сохраняют контекст. На контакте используются прежний заголовок гайда, короткое сообщение и существующая обработка обращения/событий.

Не добавлялись новые публичные обещания, тексты или дизайн. Произвольные/повторные параметры отклоняются; обычные ссылки без guide остались прежними. Канонические, hreflang и schema URL не содержат guide: это источник обращения, а не новая поисковая страница. Cookies, согласия, рекламные настройки, геобаза и контакты команды не менялись.

## Компромисс

Три страницы услуг теперь серверно рендерятся на запрос из-за чтения searchParams. Мобильный CTA получает guide после гидратации; до неё доступна прежняя обычная кнопка связи. Главные/гайды и другие страницы не получили зависимость от query reader. Дополнительного хранения посетителя нет.
