# Сохранённые формы и источники контактов — 02.10.2026

## Что готово

Закрытый read-only JSON-отчёт `/api/admin/inquiries/report?from=2026-09-26&to=2026-10-01` использует существующую сессию администратора. Независимый от интерфейса запуск:

```bash
npx tsx scripts/report-inquiries.ts 2026-09-26 2026-10-01
```

CLI использует настроенные NEXT_PUBLIC_SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY из окружения проекта, не печатает их. Не запускать с чужим окружением. Обе даты включительно по Алматы; можно выбрать до 366 дней, включая неполный текущий день. Поля периода в JSON содержат фактические границы UTC и время запуска. Секреты/имена/контакты/сообщения не выбираются. Отчёт не отправляется внешним счётчикам.

Считаются все сохранённые формы за период, а не последние 200 записей админки. UUID-курсор, страницы по 500, exact count, предел 50 000: ошибка/неполнота прекращает отчёт. Исключаются только два проверенных QA UUID в `src/lib/inquiries/report-exclusions.ts`; запись со статусом REJECTED сама по себе остаётся в отчёте. Новые тестовые заявки нужно явно проверить и добавить в allowlist через review, не исключать автоматически по имени/домену/фразе.

В `breakdown` совместно сгруппированы источник UTM, medium/campaign, отдельный referrerHost, посадочная, страница отправки, код участка, язык, контактный канал и текущая стадия. Отсутствующее поле null означает неизвестное, не «прямой заход». Статусы — существующие NEW/CONTACTED/MEETING/DEAL/REJECTED, их значения отражают состояние во время чтения; это не история переходов и не транзакционный снимок.
