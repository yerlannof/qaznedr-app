# Брендбук QAZNEDR · рабочая редакция 01

Двенадцать страниц. [Просмотр HTML](brand-book.html), [PDF](qaznedr-brand-book-v1.pdf). В PDF показан текущий векторный кандидат A3, а не шрифтовая подстановка логотипа. Точные геометрия, наборная пара и новые носители остаются на утверждении.

## Сборка и проверка

`python3 docs/design/brand/book/build-book.py` создаёт HTML; `node docs/design/brand/book/export-book.cjs` через установленный Playwright/Chrome создаёт PDF. Для Node использовать доступные зависимости рабочего окружения, ничего не устанавливать.

Проверка `qa.json`: 12 страниц без наложения содержимого на нижний колонтитул, нет отсутствующих изображений и ошибок браузера, мобильный HTML не имеет горизонтального переполнения при 375 px. PDF открыт через pypdf: 12 страниц, текст извлекается. Все страницы отрисованы Poppler и просмотрены; китайская типографика и последние страницы с данными проверены крупно. После последней правки логотипа страницы 3–4 переотрисованы и проверены повторно.

Исходные ImageGen-иллюстрации сохранены без изменения. Типографика локальная: Source Serif 4 / IBM Plex Sans, системный CJK. Лицензии шрифтов и источники находятся в `../fonts/`. PDF — RGB-документ для цифрового просмотра; он не объявляется цветопробой или готовым тиражным оригинал-макетом.
