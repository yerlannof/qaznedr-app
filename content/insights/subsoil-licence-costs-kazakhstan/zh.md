底土利用许可证涉及的国家费用以月核算指数（MRP）计算。自2026年1月1日起，1个MRP为**4,325坚戈**（《2026–2028年国家预算法》第7条）。下文金额均按此数值折算；其他年份须按新的MRP重新计算。相关规定已按《底土与底土利用法典》和《税法典》截至2026年11月11日的文本核对。

许可证的成本并不是一笔费用。其中包括一次性签约奖金、每年的费用和义务、作业后果消除保证，以及准备文件和开展作业本身的支出。

## 概览：各类许可证需支付什么

| 费用或义务         | 个体小规模采矿许可证                               | 固体矿产勘查许可证                                      |
| ------------------ | -------------------------------------------------- | ------------------------------------------------------- |
| 签约奖金（一次性） | 按面积为9、12或15个MRP：38,925、51,900或64,875坚戈 | 100个MRP：432,500坚戈                                   |
| 每年底土区块使用费 | 《税法典》第621条未规定个体小规模采矿的费率        | 每个区块每年15个MRP起：区块少于70个时每个区块64,875坚戈 |
| 每年最低作业支出   | 关于最低支出的第192条仅适用于勘查                  | 每年1,200个MRP起：前三年1个区块为5,190,000坚戈          |
| 作业后果消除保证   | 银行存款质押或银行保函；每公顷费率由州政府确定     | 按区块数量和MRP，依授权机关的方法计算                   |
| 许可证期限         | 3年，可延期1次，再延3年                            | 6年，可延期1次，最长5年                                 |

本文不涉及通过拍卖取得的许可证：其签约奖金由拍卖结果确定。

## 签约奖金

签约奖金在许可证颁发后一次性缴纳，最迟不超过颁发之日起10个工作日，按缴纳当日的MRP计算（《税法典》第762条、第764条）。

| 许可证                              | 费率     | 按MRP 4,325坚戈 |
| ----------------------------------- | -------- | --------------- |
| 个体小规模采矿，面积不超过17,000 m² | 9个MRP   | 38,925坚戈      |
| 个体小规模采矿，17,000至33,000 m²   | 12个MRP  | 51,900坚戈      |
| 个体小规模采矿，33,000至50,000 m²   | 15个MRP  | 64,875坚戈      |
| 固体矿产勘查                        | 100个MRP | 432,500坚戈     |
| 固体矿产开采（供比较）              | 200个MRP | 865,000坚戈     |

个体小规模采矿区面积为500 m²至5公顷（《底土法典》第269条），因此按面积分档的费率止于50,000 m²。

## 个体小规模采矿：还需考虑什么

- **作业后果消除保证。** 以银行存款质押或二级银行保函形式提供。金额取决于以公顷计的矿区面积和申请当年的MRP，每公顷的标准由州地方执行机关确定（第274条）。因此具体金额须就本矿区向州政府确认。
- **土地复垦。** 许可证终止后，须在六个月内完成受扰动土地的复垦（第273-1条）。
- **采矿计划与环境鉴定。** 如第一年需要使用机械，申请时须附个体小规模采矿计划。只有在该计划取得国家环境鉴定肯定性结论后，才可使用机械作业（第265条、第273条）。
- **自有设备。** 卡车、钻探设备、挖掘机或推土机须在第270条限制范围内归持证人所有。
- **文件。** 申请所附复印件须经公证，申请及文件须以哈萨克语和俄语编制。矿区须注明拐点坐标和面积（第265条）。
- **同意。** 在私有土地、他人使用的土地或他人的底土区块上开展个体小规模采矿，须取得其同意（第264条）。

申请程序详见[个体小规模采矿许可证指南](/zh/insights/artisanal-mining-licence-kazakhstan)。

## 固体矿产勘查：每年的费用和义务

**底土区块使用费。** 每个区块每年缴纳，最迟不超过2月25日，按纳税期第一天的MRP计算（《税法典》第621条、第623条）。如许可证在2月1日之后取得，按实际月数计算。前36个月的费率为：区块少于70个时每个区块15个MRP，70至120个区块时30个MRP，120个区块及以上时40个MRP。此后费率提高；完整表格见[固体矿产勘查许可证指南](/zh/insights/solid-minerals-exploration-licence-kazakhstan)。

**最低勘查支出。** 这不是向国家缴纳的费用，而是必须投入矿区作业的最低金额（《底土法典》第192条），按报告年度1月1日的MRP计算。

| 勘查第1–3年        | 每年费率     | 按MRP 4,325坚戈 |
| ------------------ | ------------ | --------------- |
| 1个区块            | 1,200个MRP   | 5,190,000坚戈   |
| 2–5个区块          | 1,800个MRP   | 7,785,000坚戈   |
| 6–10个区块         | 2,300个MRP   | 9,947,500坚戈   |
| 超过10个的每个区块 | 另加120个MRP | 另加519,000坚戈 |

自第四年起，2个及以上区块的最低支出提高；1个区块自第七年起提高。地质、地球化学和地球物理工作、钻探、探槽、野外营地、运输、设计文件及矿区其他作业均可计入。管理费用不得超过申报总额的20%。购买底土利用权、界标和土地规划、对土地使用者的补偿不计入。未达到最低支出的，须在报告年度结束后四个月内补足并报告。区块使用费和最低支出方面未纠正的违规将导致许可证无法延期（第193条）。

**申请时就需要准备最低支出所需资金。** 申请须附申请人具备第一年最低勘查支出资金的证明：哈萨克斯坦银行对账单、贷款或融资协议，或经审计的财务报表（第187条第5款）。此外还须有在编、签约或承包商处的地质师或地球物理师（第187条第6款）。

**作业后果消除保证。** 主管机关审查申请后发出通知，申请人提供保证后颁发许可证（第188条）。金额按区块数量和MRP，依授权机关的方法计算（第198条）。保证形式可以是保函、银行存款质押或保险（第55条第4款）。

**历史费用。** 2017年12月31日之后颁发的固体矿产勘查或开采许可证，如所涉区域在2018年1月1日之前未曾签订底土利用合同，则不产生历史费用补偿款（《税法典》第767条第2款）。其他情况须另行核查。

## 示例：1个区块，勘查第一年

假设1个区块的勘查许可证于2026年1月颁发。

| 项目                            | 金额          | 去向             |
| ------------------------------- | ------------- | ---------------- |
| 签约奖金，100个MRP              | 432,500坚戈   | 国家预算         |
| 区块使用费，每个区块每年15个MRP | 64,875坚戈    | 国家预算         |
| 最低勘查支出，1,200个MRP        | 5,190,000坚戈 | 矿区作业         |
| 作业后果消除保证                | 按方法计算    | 保函、质押或保险 |

不计保证和超出最低标准的支出，合计约570万坚戈。这是法律规定的下限，而不是项目预算：矿区的实际作业通常需要更多资金。

## 法律未规定的费用

这些费用的价格取决于市场和矿区本身，因此本文不给出具体金额：

- 编制勘查计划或个体小规模采矿计划，以及必要时的环保文件；
- 坐标、地形测量和边界相关工作；
- 地质服务：选区、分析档案资料、野外工作、取样和化验；
- 用于作业后果消除保证的银行保函或存款质押；
- 复印件公证以及翻译成哈萨克语和俄语。

开采环节的税费和一般税费是另一个话题，本文不作说明。
