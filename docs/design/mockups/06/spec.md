# 06 — гайды, статьи и металлы

Статус: дизайн-предложение. Задача — показать структуру чтения, а не выпустить юридические или геологические справочные материалы. [Общая система](../../brand/brand.md).

## Хаб материалов

Заголовок, короткое описание, фильтры по теме и языку, список материалов. Темы: геология, лицензирование, сделки, регионы. Карточка/строка показывает тип материала, заголовок, краткий анонс и язык. Даты/авторы — только если известны; в демонстрации они обозначены как ожидающие редактора. Пустой результат имеет сброс фильтров. Не имитировать готовую библиотеку утверждённых статей.

## Статья

1. Название, тема, язык, поле даты обновления.
2. «Коротко» — краткий ответ на вопрос, 3–4 строки, без рекламного абзаца.
3. Оглавление с якорями. На телефоне компактный раскрываемый блок; фокус после выбора остаётся предсказуемым.
4. Основной текст, поясняющая таблица, примечания.
5. Источники с названием, датой проверки и рабочими ссылками после редакторской проверки.
6. Контакт по теме и связанные материалы.

Для демонстрации выбран безопасный материал «Как читать тизер участка»: код, открытые параметры, источники данных и состав закрытого пакета. Таблица — поля тизера и пояснения, а не выдуманное соответствие классификаций запасов. Сопоставление ГКЗ / KAZRC / JORC / GB/T 17766 требует отдельной экспертной работы; не показывать их как взаимозаменяемые. Законодательные сноски в шаблоне — явные места для редактора, без выдуманных номеров актов и ссылок.

## Страница металла

Короткий предметный абзац → таблица/карточки направлений портфеля → контекст изучения → частые вопросы → связь. В первом визуальном примере медь, в китайском допускается золотое направление. Остальные шаблонные направления: свинец-цинк, молибден, вольфрам и железо. Наличие шаблона не означает готовые данные по каждому металлу.

Использовать общие демонстрационные коды и правила статусов из 04. Координат нет. Таблица показывает код, металл, регион/тип, наличие сведений о содержании, статус и ссылку. Не писать рыночные прогнозы, цену или объём запасов без актуального источника. Генеративные изображения — условные образцы, без заявлений об их реальном составе.

## Чтение на трёх ширинах

| Параметр     | 375                                                   | 768                        | 1440                                     |
| ------------ | ----------------------------------------------------- | -------------------------- | ---------------------------------------- |
| Поля         | 20 px                                                 | 32 px                      | Контент до 1200 px                       |
| Текст статьи | 16 px / 1.7                                           | 17 px / 1.7                | 18 px / 1.7, колонка примерно 680–760 px |
| Оглавление   | Раскрываемый блок в потоке                            | В потоке / сбоку при месте | Боковая колонка до 220 px                |
| Таблица      | Собственный горизонтальный скролл с понятной подписью | Компактная таблица         | Полная таблица в колонке                 |
| Контакт      | Одна плавающая кнопка + завершающий блок              | То же                      | Завершающий блок, ссылка в шапке         |

Китайский — системный CJK sans без разрядки, достаточная высота строки. Не заставлять китайскую статью повторять латинские переносы. Ссылки различимы без цвета; якорям нужен отступ от закреплённой шапки. Движение внутри чтения не требуется.

Lucide: `Search`, `ChevronDown`, `ArrowUpRight`, `FileText`, `ExternalLink`, `MessageCircle`. Декоративные гравюры отделены от таблиц и не ухудшают фон текста.
