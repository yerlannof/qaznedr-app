## Техническая правка

Сейчас прямой переход из статьи на contact теряет её тему: prefills общие, события не содержат guide. Сохраняем контролируемый `guide=<registry slug>` на прямых контактных ссылках статьи (текст, CTA, меню/футер). Contact принимает только реально существующий slug, отбрасывает массивы и произвольные строки. Тема — уже утверждённое локализованное короткое название гайда; сообщение остаётся коротким с существующей вводной qaznedr.kz. WeChat и WhatsApp получают одинаковый контекст. Форма сохраняет исходный публичный путь статьи; аналитика получает только проверенный slug, без URL query/личных данных. При смене языка контактной страницы guide сохраняется; сброс контекста работает. Для контактов без guide прежнее поведение сохраняется, согласие и настройки рекламы не меняются. Дизайн использует существующую строку темы/сброса, без нового оформления и новых маркетинговых текстов.

Критерии: TDD неизвестного/многозначного guide, переходы всех4локалей, согласованность WA/WeChat и формы, фильтрация analytics payload, сохранение service-only сценария. Build/lint/full tests/browsers/review до push.

Поисковый мотив основан на двух показах GSC, не на доказанном большом спросе. Новую статью публиковать после конкретного утверждения готового пакета; этот этап готовит результат для такого решения.
